# WP74 C1b 色意味論一括移行レポート

日付: 2026-07-11

対象: `agent/wp74-color-c1b` / 旧 baseline `c0a46452dbb89f96e001e147fce8ee9b0d43b1ee`

## 結論

WP74 C1b を実装した。`resolver_version: 2` は SDR の `scene` と `display` を
`B8G8R8A8_SRGB`、HDR の `scene` を `R16G16B16A16_SFLOAT` に解決し、既存の B8 channel
order を保持する。全経路の transfer owner は terminal `output_transform` に一本化した。
SRGB frame target では hardware encode、UNORM fallback でのみ IEC 61966-2-1 OETF shader
を使う。alpha は両経路で straight のまま transfer しない。

glTF の baseColor/emissive は SRGB view、normal/MR/AO/VAT は UNORM view で読む。
RGBA8 dual-use texture は Vulkan 1.3 の mutable image format list から UNORM/SRGB の二 view
を生成する。本エンジンの要求 API は Vulkan 1.3 であり image format list は core 機能なので、
対応 device 上に「mutable 非対応」分岐は存在しない。SRGB sample/filter capability が不足する
device は起動時に明示的に拒否する。別 image 複製を黙って選ぶより、この最小 API 契約を根拠に
一 image・二 view を決定した。

## 実装上の決定と根拠

- `fullscreen.frag` の `pow(1/2.2)` を削除した。HDR off は ACES 近似 curve まで、HDR on は
  scene-linear 出力までを担当する。
- `shader_lab_bloom_composite`、`shader_lab_present`、`shader_lab_gltf_lighting` の
  `pow(0.92)` は creative look の所有根拠がなく terminal transfer と競合するため削除した。
- `output_transform` を実在する fullscreen pass とし、frame target への copy を置換した。
  SRGB target は shader OETF なし、UNORM target の compile define でだけ piecewise OETF を有効にする。
- HDR graph は scene/bloom を float16 のまま処理し、tone curve を一度だけ適用してから UI/debug を
  display に合成する。terminal pass は常に最後である。
- authored light RGB は parse 時に IEC sRGB decode し、alpha と intensity はそのまま保持する。
  `Pelican::srgb()` も RGB のみ decode する。無印 DebugDraw/DebugText `vec4` は従来どおり linear。
- glTF `COLOR_0` と `baseColorFactor` は multiplier なので decode しない。
  `emissiveFactor * KHR_materials_emissive_strength` は unclamped float radiometric 値として保持する。
- 現行 UI schema に atlas/page や authored scalar skin color はない。既存の per-image UI texture を
  SRGB image として扱い、color/data を同一 atlas page に混在させない。未実装 atlas を推測して追加しない。
- capture contract 2 は `get_status.color` と `capture` に `contract: 2`、`encoding: "srgb"`、
  format/path/capture availability を公開する。windowed swapchain は surface と format が
  `TRANSFER_SRC` を満たす場合だけ capture 可能で、満たさない場合は `unavailable_windowed` を返す。
  PNG は color chunk を付けず、encoded-sRGB RGB / straight alpha と文書化した。

## WP72 条件 3〜5 への対応

- 条件 3: shader_lab の三つの `pow(0.92)` は所有者不明の transfer と判断して削除した。
  emissive factor は texture への量子化／clamp を廃止し radiometric float とした。UI は現行 per-image
  texture を SRGB 化し、存在しない atlas に color/data を混在させていない。
- 条件 4: manifest の全 `visual_review` を上の Golden 差分、graph trace、analytic fixture に振り分けた。
  差分理由のない baseline 更新はない。DCC 専用 capture script は repository にないため、外部連携は
  contract 2 の `encoding: srgb` metadata を境界とする。
- 条件 5: RPC/status/capture consumer を contract 2 に更新し、PNG の metadata-less sRGB 解釈を
  public header と Golden README に記録した。windowed capture は capability 条件を response に公開する。

# WP117 完了報告 — M-PBR0b OpenPBR surface + 写像表

日付: 2026-07-17
対象: `docs/design_usd_openpbr.md` v2.1 §1-2 / `docs/implementation_plan.md` WP117
基盤: WP116 (M-PBR0a) の凍結 ABI

## 1. 結論

WP116 の `PelicanSurfaceV1`、material lowering、六 variant routing、primitive binding ABI を変更せず、
OpenPBR Surface 1.1.1 の real-time subset を wrapper-B 形式で実装した。

- `{opaque,mask,blend} × {single,double}` の薄い `.surface` wrapper 6 個
- BRDF/lighting を単一の登録済み engine GLSL include に集約
- base/specular/IOR/coat 1 層/emission/normal/alpha の数表規範と numeric fixture
- UsdPreviewSurface / MaterialX OpenPBR allowlist / glTF KHR の写像表
- unsupported input の寄与条件付き WARN runtime 面
- example coat material と production wrapper を通す coat sphere image golden

正式 gate は Debug full build、CTest 448/448、golden 5/5・SKIP 0、player 8.091 秒を完走した。

## 4. wrapper-B と forward state

全 wrapper は 19 params、18 textures を同じ名前・順序・型・default・colorspace で宣言する。
違いは alpha mode 定数、double-sided 定数、blend/cull/depth state のみである。

| stable variant 名 | resource | alpha | cull | depth | WP116 target |
|---|---|---|---|---|---|
| `opaque_single_sided` | `opaque_single.surface` | opaque | back | read/write | `forward_opaque` |
| `opaque_double_sided` | `opaque_double.surface` | opaque | none | read/write | `forward_opaque` |
| `mask_single_sided` | `mask_single.surface` | mask discard | back | read/write | `forward_opaque` |
| `mask_double_sided` | `mask_double.surface` | mask discard | none | read/write | `forward_opaque` |
| `blend_single_sided` | `blend_single.surface` | blend | back | read-only | `forward_transparent` |
| `blend_double_sided` | `blend_double.surface` | blend | none | read-only | `forward_transparent` |

MASK は `geometry_opacity < alpha_cutoff` のときだけ discard し、境界値は keep する。BLEND だけ
`geometry_opacity` を出力 alpha に使い、OPAQUE/MASK は出力 alpha 1 とする。六 resource は manifest
の安定順で列挙され、それぞれ独立した shader/pipeline cache key になる。

## 5. 公開 library 境界

| public surface | 使用内容 |
|---|---|
| `pelican_surface_v1.glsl` | `PelicanSurfaceInputV1`, `PelicanSurfaceV1`, `PelicanLightV1` |
| `__pelican_surface_params.glsl` | surface 宣言から生成される `pelican_param_*` / `pelican_sample_*` accessor |
| `pelican_lighting_v1.glsl` | `pelican_light_count`, `pelican_light`, `pelican_shadow`, `pelican_env_ambient` |
| `openpbr_lighting.glsl` | 上記 public surface だけで GGX、Schlick Fresnel、diffuse、coat、emission、normal、alpha を合成 |

`openpbr_lighting.glsl` は `pelicanLights`、`pelicanFrame`、`PELICAN_SET_*`、`layout(set...)`、
private include を参照しない。standard/toon と同じ非特権 B-layer 制約である。

## 6. v1 subset 数表規範

color 定数は scene-linear、color texture は sRGB decode 後 scene-linear、data texture は linear。
normal は tangent-space RGB (`[0,1] → [-1,1]`) である。

| input | type | unit / range | default | value CS | texture CS / channel |
|---|---|---|---|---|---|
| `base_weight` | float | unitless `[0,1]` | `1` | linear | linear / R |
| `base_color` | color | reflectance `[0,1]` | `(0.8,0.8,0.8)` | scene-linear | sRGB / RGB |
| `base_diffuse_roughness` | float | unitless `[0,1]` | `0` | linear | linear / R |
| `base_metalness` | float | unitless `[0,1]` | `0` | linear | linear / R |
| `specular_weight` | float | `[0,+∞)`; UI soft max 1 | `1` | linear | linear / R |
| `specular_color` | color | tint `[0,1]` | `(1,1,1)` | scene-linear | sRGB / RGB |
| `specular_roughness` | float | unitless `[0,1]` | `0.3` | linear | linear / R |
| `specular_ior` | float | ratio `[0,+∞)`; UI soft 1–3 | `1.5` | linear | linear / R |
| `coat_weight` | float | unitless `[0,1]` | `0` | linear | linear / R |
| `coat_color` | color | tint `[0,1]` | `(1,1,1)` | scene-linear | sRGB / RGB |
| `coat_roughness` | float | unitless `[0,1]` | `0` | linear | linear / R |
| `coat_ior` | float | ratio `[0,+∞)`; UI soft 1–3 | `1.6` | linear | linear / R |
| `coat_darkening` | float | unitless `[0,1]` | `1` | linear | linear / R |
| `emission_luminance` | float | cd/m² `[0,+∞)`; UI soft max 1000 | `0` | linear | linear / R |
| `emission_color` | color | chromaticity scale `[0,1]` | `(1,1,1)` | scene-linear | sRGB / RGB |
| `geometry_opacity` | float | coverage `[0,1]` | `1` | linear | linear / R |
| `geometry_normal` | normal | normalized unit vector | geometry normal | linear | linear / tangent RGB |
| `geometry_coat_normal` | normal | normalized unit vector | geometry normal | linear | linear / tangent RGB |
| `alpha_cutoff` | float | coverage `[0,1]` | `0.5` | linear | なし; import metadata |

`.surface` の `geometry_normal_scale` / `geometry_coat_normal_scale` は Pelican の補助 param で、
OpenPBR normal input は各 normal map に保持する。fixture は input 名と texture/scale 保存先の両方を持つ。

numeric fixture は次を固定する。

- base color × weight: `(0.2,0.4,0.8) × 0.5 = (0.1,0.2,0.4)`
- IOR 1.5 の F0: `0.04`
- coat IOR 1.6 の F0: `0.0532544378698225`
- emission: `(0.25,0.5,1.0) × 4 = (1,2,4)`
- flat normal decode: `(0.5,0.5,1) → (0,0,1)`
- mask: alpha = cutoff は keep、未満は discard
- blend: opacity `0.35` → output alpha `0.35`

## 7. import 写像表

完全な machine-readable 表は `test/fixtures/openpbr/mapping_v1_1_1.json` に置いた。

| source | source input | target / rule |
|---|---|---|
| UsdPreviewSurface | `diffuseColor` | `base_color`; `base_weight=1` |
| UsdPreviewSurface | `metallic`, `roughness`, `ior` | `base_metalness`, `specular_roughness`, `specular_ior` |
| UsdPreviewSurface | `emissiveColor` | 最大成分で `emission_color` と `emission_luminance` に分解 |
| UsdPreviewSurface | `opacity`, `normal` | `geometry_opacity`, `geometry_normal_map` |
| MaterialX `open_pbr_surface` | subset 同名 input | constant/image の R/RGB/normal を同名 param/map へ写像 |
| glTF core | base color RGB/A | `base_color` / `geometry_opacity` |
| glTF core | metallic/roughness/normal | `base_metalness` / `specular_roughness` / `geometry_normal_map` |
| `KHR_materials_specular` | factor/color | `specular_weight` / `specular_color` |
| `KHR_materials_ior` | `ior` | `specular_ior` |
| `KHR_materials_clearcoat` | factor/roughness/normal | `coat_weight` / `coat_roughness` / `geometry_coat_normal_map` |
| glTF emission | `emissiveFactor × emissiveStrength` | `emission_color` / `emission_luminance` |
| glTF state | `alphaMode`, `alphaCutoff`, `doubleSided` | WP116 routing / `alpha_cutoff` |

MaterialX allowlist は surface node `open_pbr_surface`、value node `constant` / `image`、channel
`r` / `rgb`、utility `normalmap` / `texcoord` / `transform2d`、colorspace
`srgb_texture` / `scene_linear` / `raw` に限定する。任意 nodegraph と unsupported lobe は reject として
fixture に固定した。

## 8. unsupported WARN

固定 code は `OPENPBR_UNSUPPORTED_INPUT`。次の論理式だけで発行する。

```text
(authored && authored_non_default) || (connected && connection_contributes)
```

単に node/input が存在する場合、default authored、未接続、非寄与 connection は無音である。
出力は順序も含めた固定 4 field の compact JSON とした。

```json
{"code":"OPENPBR_UNSUPPORTED_INPUT","prim_path":"/World/Looks/Paint","input":"fuzz_weight","fallback":"0.0"}
```

runtime 面は `src/project/openpbrmapping.hpp/.cpp` にあり、U-USD0c はこの境界を再利用できる。

## 11. WP116 ABI 不変

`pelican_surface_v1.glsl`、WP116 の material format/lowering、六 state routing、primitive binding 実装には
変更を加えていない。追加は engine resources、OpenPBR GLSL/wrapper、写像/WARN helper、example、fixture、
test/golden に限定した。既存 material の public-C byte golden と既存 40 RGBA8 hash が不変であることも
上記 gate で確認した。

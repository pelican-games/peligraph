# WP177 VRMA-R0 完了レポート

日付: 2026-07-19
対象: `agent/wp177-vrmar0`

## 1. 結論

WP176 の immutable `VrmaClip` / source rig / body・expression・gaze typed
channel と、VRM-S0 の target `VrmSemanticData` / `SkeletalModelData` を入力に、
VRM humanoid 専用の版付き retarget/application profile v1 を実装した。

profile は source humanoid bone から target humanoid bone への解決済み写像、
source/target rest local TRS、hips 身長比、root-motion policy の将来枠、source clip
provenance、profile version、source/target rig SHA-256 を一体で保持する。出力の
`VrmaRetargetedClip::sample(time)` は target rig node index 順の local TRS と、
Pose へ混ぜない expression / gaze sample を返す。

本 WP は R0 中間表現までである。AnimationSource 化、graph/timeline 接続、instance
適用、sink authority、hot reload generation は行っていない。WP176 の decoder/model
型、AnimationServiceV1、anim graph、公開 ABI、renderer、communication、editor、ECS
にも変更を加えていない。

## 2. Versioned profile と保持情報

| 型/field | v1 の意味 |
|---|---|
| `VrmaRetargetProfileOptions::version` | 受理値は `1`。未知 version は fail-fast |
| `root_motion_policy` | v1 は `preserve_hips_translation` だけ。抽出 mode は未実装の将来枠 |
| `bone_mappings` | source human bone ごとの source/target node と両 rest local TRS。target にない optional は `target_node=-1` |
| `hips_translation_scale` | source/target の rest world hips 高さ比。hips translation channel にだけ適用 |
| `provenance.source_clip` | source URI、`#animation/0`、content SHA-256、import profile、tool version をコピー保持 |
| `provenance.profile_version` | source provenance と合成する R0 profile version |
| `source_rig_sha256` / `target_rig_sha256` | node order、parent、名前、float bit、humanoid map（target は expression inventory も含む）の canonical SHA-256 |

source/target hierarchy は parent 範囲と cycle を検査する。source node の matrix は
finite affine・非ゼロ scale・shear/reflection なしの場合に local TRS へ分解する。
required 15 bone の欠落、duplicate bone/node、invalid node、zero quaternion、非 finite
track、不正な key 時刻・tangent shape は profile 公開前に reject する。

## 3. Retarget 式の導出

### 3.1 Local rotation の rest/T-pose 正規化

source bone の rest local rotation を \(q_{s0}\)、時刻 \(t\) の glTF local rotation
sample を \(q_s(t)\)、target bone の rest local rotation を \(q_{t0}\) とする。

まず source animation を source rest からの相対回転へ戻す。

\[
\Delta q(t) = q_{s0}^{-1} q_s(t)
\]

次に同じ相対回転を target rest に再適用する。

\[
q_t(t) = q_{t0}\,\Delta q(t)
       = q_{t0} q_{s0}^{-1} q_s(t)
\]

この順序なら source が rest のとき \(q_s(t)=q_{s0}\) なので
\(q_t(t)=q_{t0}\) となる。source と target が同じ rest のときは
\(q_t(t)=q_s(t)\) となり、恒等 fixture を満たす。各入力と演算結果は normalize
し、quaternion 比較は符号反転同値を考慮して `abs(dot)==1` を許容誤差
`1e-5` で検査した。

target world transform は通常どおり parent から再帰合成する。

\[
W_t(n) = W_t(parent(n))\,L_t(n)
\]

親子の繋ぎ直しはしていない。従って optional bone 欠落はその track の skip だけで、
子を欠落 bone の親へ付け替える挙動はない。

### 3.2 Hips translation と身長比

source/target rest hierarchy を world へ合成し、Y-up VRM 空間で hips rest world
位置の高さをそれぞれ \(h_s\)、\(h_t\) とする。scale は次である。

\[
r = \frac{|h_t|}{|h_s|}
\]

source hips rest local translation を \(p_{s0}\)、sample を \(p_s(t)\)、target
rest local translation を \(p_{t0}\) として、target local translation は次になる。

\[
p_t(t) = p_{t0} + r\left(p_s(t)-p_{s0}\right)
\]

source の rest offset を一度除き、移動量だけを身長比で scale して target rest に
戻すため、恒等 rig では入力一致し、target hips 高さ 2 倍 fixture では XYZ の移動量と
rest 高さが 2 倍になる。zero hips height は比を定義できないため、translation track が
ある場合に名前付き error とする。hips sample は body channel のままで、root-motion
delta の抽出・object transform への適用は行わない。

## 4. Typed channel と sampling

- body rotation: LINEAR は shortest-path slerp、STEP は左 key、CUBICSPLINE は glTF の
  component-wise Hermite（tangent に key 間隔を乗算）後に quaternion normalize
- hips translation: LINEAR / STEP / CUBICSPLINE を sample 後、§3.2 の式を適用
- expression: preset/custom namespace と名前だけを target semantic に照合し、weight
  track は identity sample。target に名前がなければ skip + warning
- gaze: bone mapping をせず、offset と rotation track を identity sample
- channel のない target node: target rest local TRS を維持
- sample 時刻: clip の `[start,end]` へ clamp。NaN/Inf は reject

warning は source channel 順に安定して格納する。optional bone と expression の欠落は
区別した enum、subject、説明文字列を持つ。

## 6. VRMA-I0 への引き継ぎ

| R0 から渡すもの | I0 で追加すべきもの | R0 で行っていないこと |
|---|---|---|
| immutable target-local clip、完全な target rest pose、解決済み bone mapping | typed AnimationSource / cursor と graph/timeline adapter | AnimationServiceV1 / anim graph / 公開 ABI 変更 |
| `sample(time)` の local TRS | caller-owned PoseView への転送、rig generation/stale 検査 | instance palette commit、renderer 接続 |
| expression / gaze sample | expression/gaze typed sink と同一 frame revision commit | expression bind適用、lookAt application |
| warning 一覧、source/target rig hash、DCC provenance + profile version | asset generation、hot reload reset/rebind、status/trace identity | reload watcher、sink authority/handoff |
| hips translation（未抽出） | 将来 version の明示的 root-motion policy が導入された場合だけ sideband 化 | 暗黙の root motion 解釈、object transform writer |

I0 は R0 の expression/gaze を joint Pose に畳まず、target-local body pose と別の typed
sink へ渡すこと。profile version または rig hash が変わった場合は、旧 cursor/pose を
暗黙再利用せず generation 不一致として reset/rebind すること。

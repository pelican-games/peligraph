# WP91 実装レポート: 入力 I4 — ゲームパッド + バインディングプロファイル

日付: 2026-07-12

## 実装結果

GLFW gamepad API を既存 `os` 入力経路へ統合した。新しい build unit や依存は追加して
いない。ゲームパッドの button / axis 変化は `InputEvent::gamepad_button` /
`InputEvent::gamepad_axis` になり、`InputState` が付番する既存の単調増加 `event_seq`、
frame freeze、`pelican.input_seq` v1 の収録・リプレイを keyboard/mouse と共有する。

GLFW 固有部は `GamepadStateSource` と `GamepadEventPoller` の境界で分離した。production
source は `glfwJoystickIsGamepad` / `glfwGetGamepadState` を使い、fixture は fake source
を注入する。active profile に `pad:` binding が無い場合、poller は source の `read` を
一度も呼ばない。切断時は保持中 button の release と非ゼロ axis の zero event を出す。

## プロファイル分離

`pelican.input_actions` v1 は action set / name / type だけを持つ定義アセットにした。
inline `bindings` は名前入りエラーにし、旧形式の互換受理は追加していない。binding は
次の `pelican.input_profile` v1 に分離した。

```json
{
  "schema": "pelican.input_profile",
  "version": 1,
  "name": "gamepad",
  "bindings": [
    {"action": "move", "binding": "pad:left_stick", "deadzone": 0.2, "invert_y": true},
    {"action": "jump", "binding": "pad:a"}
  ]
}
```

- project: `basic_config.input_profiles` と `basic_config.input_profile`
- startup: `--input-profile <name>`（project 既定値を上書き）
- RPC: `set_input_profile {"name":"arcade"}`
- status: `get_status.input.profile / profiles / gamepad_polling`

標準 GLFW control 名を profile parse 時に解決する。未知 button / axis、action type と
control の不一致、範囲外 deadzone、不正な invert 属性は profile/action/control 名を
含むエラーにする。deadzone は axis1 では一次元、stick では radial に適用し、反転は
deadzone 後に適用する。example に keyboard / gamepad / arcade の 3 profile を追加し、
筐体レイアウト差を profile 追加だけで表した。

## event_seq / 収録・リプレイ

input_seq v1 の安定表現を追加した。

```json
{"event_seq":10,"type":"pad_button","pad":0,"code":"a","pressed":true}
{"event_seq":11,"type":"pad_axis","pad":0,"code":"left_x","value":0.75}
```

RPC `inject_input` も `pad_button_down` / `pad_button_up` / `pad_axis` を受け、実機なしで
同じ ordered event 経路へ注入できる。既存 record/replay fixture は W key と同じ frame
に pad button/axis を収録し、新規 process 2 回の replay capture、recording capture と
replay capture の全 PNG byte 一致を検証する。

## fixture

- fake joystick source: pad 未バインド時 read 0 回、接続・変化・切断 event
- profile: gamepad `a` と arcade `b` が同じ `jump` action、deadzone、Y 反転
- unknown control: `turbo` button と `warp_stick` axis の名前入りエラー
- selection: project=`keyboard`、CLI=`gamepad`、RPC=`arcade` と polling status
- same action: CLI gamepad `a` と RPC arcade `b` の 12 frame capture が byte 一致
- input_seq: pad button/axis を含む serialize→parse→serialize の byte 一致
- record/replay: pad を含む 3 frame / 6 event の capture byte 一致

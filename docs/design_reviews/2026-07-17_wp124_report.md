# WP124 U-USD0c 実装完了レポート

日付: 2026-07-17  
対象: `pelican-import-tools` main / `pelican2` `agent/wp124-usd0c`

## 1. 結論

WP117 の OpenPBR 1.1.1 写像表、WP119 の USD prim→GLB primitive mapping、WP116 の
material/binding ABI をそのまま接続し、USD の material・PNG texture・primitive/subset binding を
決定的な Pelican delivery へ変換した。OpenPBR は tag `v1.1.1`、commit
`f8d6d947dfae4c9b599965a86c22826ea7a8dbfb` に exact pin し、manifest と material define の両方へ記録する。

MaterialX は WP118 の縮退確定どおり USD に authored された値と allowlist connection だけを解釈する。
外部 `.mtlx` graph は評価せず `USD_MTLX_PLUGIN_UNAVAILABLE` を記録する。engine production code の変更は
`pelican.import.outputs[]` に `pelican.material` version 1 を受理する追加だけであり、renderer/material 実装は変更していない。

## 2. delivery contract

| file | schema / role | contract |
|---|---|---|
| `model.glb` | `gltf` | WP119 の mesh/primitive index、named material、変換済み UV を保持 |
| `scene.json` | `pelican.scene` v1 | GLB node fragment を参照 |
| `materials.json` | `pelican.material` v1 | OpenPBR values、texture override、六 variant resource への routing |
| `material_bindings.json` | `pelican.material_bindings` v1 | `usd_path → mesh/primitive → material/routing` |
| `textures/*.png` | PNG | SHA-256 content-addressed nameで局所化 |
| `manifest.json` | `pelican.import` v1 | output hash、binding metadata、mapping、WARN、toolchain、二回決定性を記録 |

`pelican.material_bindings` は WP116 の別 document であり、WP124 の engine output schema 表を拡張しない。
manifest の `source.material_binding` から file/schema/version/SHA-256 を参照する。

## 3. WP117 写像カバレッジ

### 3.1 UsdPreviewSurface

| source input | OpenPBR target / rule |
|---|---|
| `diffuseColor` | `base_color`; `base_weight=1` |
| `metallic` | `base_metalness` |
| `roughness` | `specular_roughness` |
| `ior` | `specular_ior`（未 authored は 1.5） |
| `emissiveColor` | RGB 最大成分を `emission_luminance`、正規化 RGB を `emission_color` |
| `opacity` | `geometry_opacity`; 1 未満または map 接続は `blend` routing |
| `normal` | `geometry_normal_map` |
| authored `useSpecularWorkflow/specularColor` | `specular_color` |

WP117 表にない `opacityThreshold` から MASK を新設せず、USD v1 は表で定義済みの OPAQUE/BLEND だけを生成する。
`doubleSided` は Mesh の authored/default 値から single/double wrapper を選ぶ。

### 3.2 MaterialX OpenPBR authored subset

| group | 同名 input → target | connection |
|---|---|---|
| base | `base_weight`, `base_color`, `base_diffuse_roughness`, `base_metalness` | constant / image R・RGB |
| specular | `specular_weight`, `specular_color`, `specular_roughness`, `specular_ior` | constant / image R・RGB |
| coat | `coat_weight`, `coat_color`, `coat_roughness`, `coat_ior`, `coat_darkening` | constant / image R・RGB |
| emission | `emission_luminance`, `emission_color` | constant / image R・RGB |
| alpha | `geometry_opacity` | constant / image R |
| normals | `geometry_normal`, `geometry_coat_normal` | `normalmap → image` RGB、scale を各 Pelican scale param へ保持 |

surface node は `open_pbr_surface`（USD nodedef id も受理）、value node は `constant` / `image`、
output は `r` / `rgb` / MaterialX 標準 `out`、utility は `normalmap` / `texcoord` / `transform2d`、
colorspace は `srgb_texture` / `scene_linear` / `raw` の allowlist に限定した。任意 nodegraph と unsupported lobe は
fallback + WARN になり、表外の material 写像は追加していない。

## 4. texture と binding

- PNG は Ar resolver と authored layer anchor を用いて、通常 USD と USDZ package のどちらからも全体展開せず取得する。
- `--localization copy` を既定にし、同一 byte は同一 SHA-256 名へ集約する。既存の `record` は geometry-only 互換モードとして残す。
- source/target colorspace、R/RGB/normal channel、source asset、hash、texcoord、scale/rotation/translation を manifest に記録する。
- v1 の単一 UV transform は `TEXCOORD_0` へ決定的に bake する。複数 map の transform が衝突した場合は identity fallback と WARN にする。
- UDIM token は展開せず reject + WARN。KTX2 は既存 recipe の明示 opt-in のままで、自動連鎖しない。
- Mesh binding と `GeomSubset` binding を WP119 の安定 mesh/primitive index へ接続し、WP116 document の
  `usd_path`, `mesh`, `primitive`, `material`, `routing` を出力する。

## 5. WARN 一覧

| code | 条件 / fallback |
|---|---|
| `OPENPBR_UNSUPPORTED_INPUT` | `(authored && non_default) || (connected && contributes)` のときだけ出力。field は厳密に `code, prim_path, input, fallback` |
| `USD_MTLX_PLUGIN_UNAVAILABLE` | external `.mtlx` を評価せず authored USD values only |
| `USD_MTLX_NODE_UNSUPPORTED` | allowlist 外 surface/value/normal connection を OpenPBR default/geometry normalへ縮退 |
| `USD_TEXTURE_NODE_UNSUPPORTED` | allowlist 外 texture/UV utility を identity/defaultへ縮退 |
| `USD_TEXTURE_CHANNEL_UNSUPPORTED` | `r/rgb/out` 外 channel を constant/defaultへ縮退 |
| `USD_TEXTURE_FILE_MISSING`, `USD_TEXTURE_UNRESOLVED` | file input 不在または resolver 解決不能 |
| `USD_TEXTURE_FORMAT_UNSUPPORTED` | v1 の PNG 以外 |
| `USD_TEXTURE_COLORSPACE_UNSUPPORTED`, `USD_TEXTURE_COLORSPACE_MISMATCH` | allowlist 外、または surface slot と非互換 |
| `USD_TEXCOORD_UNSUPPORTED` | v1 の `st` / index 0 外 |
| `USD_TEXTURE_TRANSFORM_CONFLICT` | material 内 map transform が複数種類; identity bake |
| `USD_UDIM_UNSUPPORTED` | `<UDIM>` / printf tile token; constant/default |
| `USD_MATERIAL_NOT_FOUND`, `USD_MATERIAL_SURFACE_MISSING` | OpenPBR default material |
| `USD_SUBDIVISION_CAGE_USED` | subdivision surface を評価せず WP119 polygon cage |
| `USD_DEPENDENCY_NOT_LOCAL`, `USD_DEPENDENCY_UNRESOLVED` | dependency closure に解決不能状態を記録 |

coat corpus の machine-testable diagnostics は次の2件である。

```json
{"asset":"openpbr.mtlx","code":"USD_MTLX_PLUGIN_UNAVAILABLE","fallback":"authored USD values only","prim_path":"/World/Coat","severity":"warning"}
{"code":"OPENPBR_UNSUPPORTED_INPUT","fallback":"0.0","input":"fuzz_weight","prim_path":"/World/Coat"}
```

## 6. coat corpus と実描画 Golden

`root_materials_coat.usda` は authored MaterialX OpenPBR の base/specular/IOR/coat/emission/opacity、
R channel PNG、`transform2d`、double-sided binding、external `.mtlx`、unsupported `fuzz_weight` を1ケースに固定する。
生成 delivery を Golden 実行時に一時 project 化し、engine が次を実行する。

1. `pelican.import` / `pelican.material` / binding / scene を parser で読む。
2. generated whole GLB に binding document を適用する。
3. `engine://surfaces/openpbr/opaque_double.surface` で generated material を lower する。
4. localized PNG override を GPU material に登録し、generated scene の三角形へ割り当てる。
5. production renderer/framegraph で描画し、image、RGBA8 hash、execution trace、canonical plan を固定する。

![WP124 generated USD coat OpenPBR golden](../../test/golden/usd0c_openpbr_material/expected.png)

## 8. engine 変更境界

- production: `src/project/importmanifest.cpp` に `pelican.material` v1 のみを additive 受理。
- positive fixture: version 1 を受理。
- negative fixture: version 2 を明示 reject。
- generated delivery load test: manifest/material/binding/scene parse、GLB load、binding、scene instantiate。
- Golden: generated artifact の OpenPBR 実描画、RGBA8、renderer execution trace。
- renderer、material parser/lowering、surface wrapper、shader production codeの変更なし。

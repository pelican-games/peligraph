# WP106 S2D-1 strict pixel policy / flipbook 実装報告

日付: 2026-07-15

判定: **Accept**

正本: `docs/design_2d_game_layer.md` v2.2 §2-1、`docs/implementation_plan.md` WP106

## 1. 結論

S2D-1 の C4 条件を `render_only_quantization` で閉じた。logical-resolution
target、letterbox、camera snap は追加せず、物理 Transform と UI quad ABI は不変。
project / scene の camera sprite policy、CPU 判定、GPU 量子化、status/WARN、公開
Flipbook、project-code dogfood、GPU golden まで同じ契約で接続した。

## 2. 固定した C4 契約

- content viewport は framebuffer 全域、pixel center は `(n+0.5,m+0.5)`、境界は整数
- `wupp=(2*xmag/width, 2*ymag/height)`、`zoom=(1/ppu)/wupp`
- x/y zoom が相対許容差 `1e-4` 以内で同じ整数かつ 1 以上のときだけ strict active
- nearest、非 billboard、view 軸平行、source texel ごとの最終 framebuffer scale が
  x/y とも整数の sprite だけを量子化
- world/view/projection 後、projected local atlas corner を1回だけ整数境界へ丸め、
  同じ NDC delta を quad 全頂点へ加算。camera snap と二重丸めはない
- 不成立は silent fallback せず、camera/asset 名入り WARN と理由付き status に残す

project の `basic_config.sprite` と `basic_config.camera.sprite`、scene camera の
`sprite` はすべて closed schema とし、未知フィールドを名前付きで拒否する。

## 3. 観測と公開 API

`get_status.sprite`、`get_frame_plan.sprite`、sprite draw trace に以下を additive 公開した。

- method / requested / active / failure
- ppu / full viewport / wupp / zoom / integer zoom / tolerance / pixel center
- sort / logical / visible / chunks / eligible / downgrade 件数と理由

公開 `GameContext` に sprite 作成・取得・更新・texture 差し替えを追加し、非特権の
`FlipbookClip` は明示 local time だけで loop/once を決定する。`sprite_demo` のゲーム
DLL はこの API だけで user-created sprite を作り、atlas frame を 0.2 秒ごとに切り替える。
プレイヤーを public SDK の export host として whole-archive link し、未使用 helper も
ゲーム DLL から import できることを専用 link fixture で固定した。

へ再 baseline。ほかの既存 RGBA hash は不変。

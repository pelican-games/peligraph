# WP197 完了レポート — Python / test-tool build isolation

日付: 2026-07-24

## 結果

Pythonをエンジン／ゲームの通常build依存から外した。テストは標準CMakeの
`BUILD_TESTING`と`PELICAN_PYTHON_TESTS=AUTO|ON|OFF`で分離し、ローカルでは
PythonがなくてもC++/CMake suiteを保ち、完全CIだけがPython gateを必須化する。

`BUILD_TESTING=OFF`だけではpinned SPIRV-Toolsが内部でPythonを要求していたため、
experimental SPIR-V linkerも`PELICAN_WITH_SPIRV_LINK`という独立build unitへ分離した。
既定OFFではstubがruntimeのexperimental指定へ名指しの診断を返し、pinned
SPIRV-Headers/Toolsと`pelican-spv-link` CLIはbuild graphへ入らない。ON時の
toolchain revisionとテストcorpusは従来どおり固定される。

## 構成

- `BUILD_TESTING=OFF`: Catch2、全CTest、Python test gateを構成しない
- `PELICAN_PYTHON_TESTS=AUTO`（既定）: Pythonがあれば8件を登録、不在なら省略
- `PELICAN_PYTHON_TESTS=ON`: Pythonを`REQUIRED`にし、CIの欠落をconfigure errorにする
- `PELICAN_PYTHON_TESTS=OFF`: Pythonを探索せずC++/CMake testだけを登録
- `PELICAN_WITH_SPIRV_LINK=OFF`（既定）: experimental linker dependency/CLIを除外
- `PELICAN_WITH_SPIRV_LINK=ON`: pinned toolchain、実装、CLI、corpus/goldenを有効化

Python製CTestには`python` labelを付け、`python -B`と
`PYTHONDONTWRITEBYTECODE=1`の両方でsource treeへのbytecode生成を抑止した。
`__pycache__/`と`*.py[cod]`もignore対象にした。

distribution presetは`BUILD_TESTING=OFF`と`PELICAN_WITH_SPIRV_LINK=OFF`を明示する。
build-unit smokeはC++ probeを残してPython testだけOFF、project-code smokeは全testをOFFにし、
両方で`CMAKE_DISABLE_FIND_PACKAGE_Python3=TRUE`を指定してPython探索の再混入を検出する。
完全CIはPython testとSPIR-V linkerを両方ONにして逆側も検証する。

## 検証

- Python探索をCMakeで禁止した`BUILD_TESTING=OFF`構成:
  `pelican_player` / `pelican_cli` build成功
- Python探索を禁止した`BUILD_TESTING=ON` + `AUTO` + linker OFF構成:
  configure成功、Python label 0件、disabled-linker / surface / dist-config test成功
- Python探索を禁止した`PELICAN_PYTHON_TESTS=ON`構成:
  Python3 REQUIREDで期待どおりconfigure失敗
- Python test ON + linker ON完全構成:
  Debug全target build成功
- GPU-free CTest: 707 / 707成功、環境依存symlink 1件はexact allowlistどおりskip
- Python CTest: CPU 7 / 7、RPC smoke 1 / 1成功
- SPIR-V linker / surface / CLI golden重点test: 10 / 10成功
- Python test前後で既存`.pyc`の更新時刻は不変、新規cache生成なし
- `git diff --check`: 成功

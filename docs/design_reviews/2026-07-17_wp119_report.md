# WP119 — U-USD0b コンポジションと静的ジオメトリ変換 完了報告

日付: 2026-07-17

## 1. 結論

`pelican-import-tools` に `usd-core==26.5` を固定した production USD/USDZ
レシピを追加し、合成済み静的 geometry を決定的な GLB と
`pelican.scene` v1 へ変換できるようにした。material network は解釈せず、全 primitive
を `PelicanDefaultStandard` へ落とす。OpenPBR、MaterialX、texture localization は
予定どおり U-USD0c の境界に残した。

pelican2 には Y-up/m、Z-up/cm、同内容の USDZ の 3 delivery を fixture として追加し、
manifest parser、scene normalizer、GLB loader、scene instantiate を実データで通した。
さらに `root_yup_m_usda` を使う image golden を 1 件追加した。

正式 gate は import-tools pytest、指定 Python での configure、Debug full build、
CTest 449/449、golden verbose（SKIP 0）、windowed player 8 秒をすべて完走した。

U-USD0b は dependency closure を記録するが、UDIM 展開と texture copy は行わない。

## 7. スコープ境界

本変更では UsdPreviewSurface/MaterialX OpenPBR の解釈、texture/UDIM localization、
pelican.material 出力、animation/skinning/camera/PointInstancer は実装していない。
前二者は U-USD0c、後者は U-USD1/U-USD2 の対象である。仕様からの逸脱や未解決質問はない。

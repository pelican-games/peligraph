# WP151 完了レポート — ED-CODEC0 component codec 五つ組

## 1. 結論

WP151 の component codec 登録層を追加し、`transform`、`simplemodelview`、
`camera`、`light`、`collider`、`animation`、`sprite_view` の七種を
`decode authored JSON / encode canonical authored JSON / schema / runtime apply /
runtime project` の五つ組として登録した。

codec は `AuthoringSceneDocument` が保持する authored JSON を入力とし、SceneLoader
は live scene を消去する前の prepare で codec decode を完了する。codec のない
component は従来どおり raw JSON を正本として `encodeSemantic()` に保持し、query
metadata は `state=Missing`、`editable=false` を返す。

共通 schema API は増設せず、WP150 の `StructFieldSchema` と
`componentPolicy(...)` をそのまま利用した。凍結された schema 三 header、
`src/core/ecs/`、behavior / gamelogic 系には変更を加えていない。

## 2. 実装した契約

| component | codec coverage | runtime apply / project |
|---|---|---|
| transform | local TRS を authored 正本に固定。parent-child 合成と world 表示を分離 | hierarchy participant は `LocalTransformComponent` と world を同時更新。local がない query fallback は `world + parent` から local を逆算し、zero parent scale は非可逆として拒否 |
| simplemodelview | required non-empty `model`、既存 glTF `params` object を authoring passthrough | model 変更時に旧 model instance を remove/reset し、dirty rebind |
| camera | perspective / orthographic、sprite policy、orbit/follow/fly controller、旧 alias 拒否 | ECS の空 marker と分離した専用 typed adapter。SceneLoader prepare で検証後、既存 Camera load を publish |
| light | directional / point / spot の型別 field、色・cone・range 検証 | typed special adapter で canonical `LightLoadEntry` を作り `LightContainer` へ publish |
| collider | sphere / box / capsule、layer/mask/trigger/one_way | canonical `ColliderComponent` adapter を `PhysWorld` binding へ publish |
| animation | clip、正の speed、非負 start_time、JSON bool `loop` | runtime `uint8_t` と authored bool を相互変換。予約キー `graph` は従来診断を維持 |
| sprite_view | closed schema、sprite asset ref、size/pivot/layer range | `flip` は boolean 2 要素配列、`billboard` は `none/y_axis/full` 文字列として encode |

各 schema は型、range、enum、default/required と canonical field order を
ComponentPolicy descriptor として登録した。registry test は七種すべてについて五つの
callback が non-null で schema が空でないことも固定する。

## 4. raw authority と scene publish

- `AuthoringSceneDocument::rawJson()` と `encodeSemantic()` は codec の有無にかかわらず
  authored tree を変更しない。既存 `unknown_read_only` fixture は fresh load 後も semantic
  equal である。
- query は component declaration ごとに codec metadata を付与する。登録七種は
  `Registered/editable=true`、未登録 component は `Missing/editable=false` である。
- SceneLoader は七種を live clear 前に decode するため、invalid authored component が
  partially published されない。ECS component は codec apply、light/collider は special
  dispatch を通す。
- hierarchy の local→world 合成は `SceneLoaded` より前に親から順に完了する。
  `local_trs` と表示専用 `world_trs` は別 JSON node として投影される。

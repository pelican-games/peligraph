# WP78 実装レポート — マテリアル M3a B 層 source baseline

日付: 2026-07-12
対象: `agent/wp78-material-m3a`

## 決定と根拠

### source 合成とロード入口

- B 層は M3a の範囲どおり GLSL source 専用とし、`.spv` / spv-link は実装していない。
- shaderc includer に名前付き virtual include を追加した。engine template が
  `__pelican_user_surface.glsl` と生成 params shim を逆 include するため、パーサが保持する
  `source.substr(code_offset) == document.code` は不変である。
- `SurfaceCompiler` が main/depth/velocity の template・defines・virtual include を決定し、
  `ShaderLibrary::loadFromSurface` が vertex/fragment SPIR-V を実 bundle として登録する。
  これにより合成器を test/CLI 専用経路にせず、runtime shader library の正規入口にした。
- params は `pelican_param_<name>()`、textures は `pelican_sample_<name>(uv)` の生成 accessor
  を通す。binding と std140 offset は WP76 の共通 lowering を唯一の計算元にした。

### hook 反射と事故防止

- code 本体の関数定義名をコメント・文字列を除外して反射し、版付き v1 hook 集合を
  `SurfaceFormatDocument` に保持する。深さ指定 key は追加していない。
- `pelican_vertex_displace_v1` / `pelican_surface_v1` / `pelican_brdf_v1` /
  `pelican_ambient_v1` / `pelican_lighting_v1` を既知 hook とした。
- 未知 `pelican_` 関数、brdf+lighting 併存、空または既知 hook ゼロを surface 名入りの
  parse/load error にする。既存の unversioned fixture は v1 symbol へ移行した。
- v1 struct と関数 signature、排他規則、生成 accessor を `shader_contract.md` に凍結した。

### template・公開 library・pass variant

- engine resource に surface v1 vertex/fragment template、surface ABI include、lighting ABI
  includeを追加した。公開 lighting API は `pelican_light_count` / `pelican_light` /
  `pelican_shadow` / `pelican_env_ambient` である。
- standard/toon lighting は engine private helper を使わず、上記公開 API のみで記述し、
  user snippet と同じ template 合成・shaderc compile を CI で通す。
- main / `PELICAN_PASS_DEPTH` / `PELICAN_PASS_VELOCITY` は同じ vertex template と
  `pelican_vertex_displace_v1` を使う。shadow feature define + depth pass の組合せも fixture
  で compile し、影用 variant だけ変位が外れる退行を防ぐ。

### B→C lowering・example・golden

- `dump-lowered-material` に hook 集合、公開 template/library、main/depth/velocity variant を
  C-material 記述として追加した。`wp78_dump.txt` と byte exact 比較し、B 専用の非公開
  resource/state が dump から消える変更を検出する。
- `projects/example/shaders/toon.surface` と一行 surface 参照の
  `materials/toon.material.json` を追加した。material parse → lowering → production template
  compile → ShaderLibrary bundle registrationまで同じ fixture で検証する。
- golden `surface_toon` は example の authored code を virtual include し、v1 ABI と公開
  lighting call を実描画する。既存17件の RGBA8 hash は不変で、新規 hashだけを追加した。

### エラー翻訳

- user virtual include の先頭へ `#line <code開始行> "<surface名>"` を注入する。
  意図的な未宣言 symbol を authored file の6行目に置いた fixture で、shaderc log が
  `compile_line.surface:6` を返すことを固定した。template 行番号への手動文字列置換はしない。

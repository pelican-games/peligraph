# WP153 E-PROJTX0 完了レポート

日付: 2026-07-18
対象: 異種 projection の aggregate transaction

## 1. 結論

`EditorProjectionTransaction` を追加し、immutable な
`AuthoringSceneDocument` を基点に ordered command を staged next document へ
適用・検証した後、全 runtime adapter を prepare し、全成功時だけ no-throw の
publication 区間へ進む構造にした。runtime publish の完了後に限り staged document と
`SceneRevision` を `noexcept` swap するため、途中 revision や document/runtime の混在を
公開しない。

prepare、command 検証、inverse-token publish fault のいずれかが失敗した場合は、既に
publish 済みの participant を逆順 rollback し、document semantic、revision、runtime
query、EntityId/free-list/component version、Light/Phys binding、renderer handle、
lifecycle trace を実行前と一致させる。RPC、journal、behavior 実 adapter は本 WP の
範囲に含めず、behavior attachment は型付き接合点だけを用意した。

transform は authored local TRS を正本とし、対象と全 descendant の world closure を
現行 `LocalTransformSystem` と同じ合成式で prepare 中に計算する。reparent は
preserve-local / preserve-world の明示を必須とし、zero parent scale、非有限値、循環、
canonical TRS へ表現不能な結果を stable error code と object path で preflight reject
する。

## 2. transaction と adapter

| 対象 | prepare（live 不変） | publish | rollback |
|---|---|---|---|
| Authoring document / revision | ordered command を複製 JSON へ適用し、scene/object identity と codec 結果を検証 | 全 runtime 成功後に `AuthoringSceneDocument::swap`、revision を一回だけ進める | staged document を破棄。live document/revision は未変更 |
| ECS existing-value | `ECSCore::prepareComponentValue<T>` が旧値、次値、component version を token 化 | component 値と prepared version を no-throw 代入 | 旧値と旧 version を no-throw 復元 |
| ECS archetype | `EditorProjectionCallbackAdapter(EcsArchetype)` から WP152 の migration prepare 接合点を合成 | WP152 の no-throw relocate / ID ref / version / external binding publication | WP152 の prepared state または完全 inverse token を no-throw 復元 |
| Transform closure | staged document の全 local TRS と parent graph を decode、循環検査し、root から全 world closure を計算 | bound `LocalTransformComponent` / `TransformComponent` へ prepared 値だけをコピー | publication 前は prepared vector を破棄、publication 後は保存済み local/world を復元 |
| Renderer/model | `PreparedModelTrs` が handle、旧 TRS、次 TRS を確定。aggregate へは typed callback 接合 | `publishPreparedTrs` で値だけを no-throw 公開 | `rollbackPreparedTrs` が handle と旧 TRS を復元 |
| Camera | `PreparedSceneState` へ camera table、active camera、scene association を構築 | prepared state を no-throw swap | publication 前は prepared state を破棄。必要時は snapshot を swap-back |
| LightContainer | `PreparedLoad` へ light 配列、name map、shadow binding を全構築・検証 | `publishPrepared` が container state を no-throw swap | `snapshotPrepared` の旧 state を swap-back |
| PhysWorld | `PreparedState` へ collider identity、binding、transform source と ID 割当を構築・重複検証 | `publishPrepared` が binding state を no-throw swap | snapshot の旧 binding/ID state を swap-back |
| Behavior attachment | `EditorProjectionAdapterKind::BehaviorAttachment` と typed callback のみ | BEH0 が提供する no-throw callback の接合点 | BEH0 が提供する no-throw callback の接合点 |

`EditorProjectionCallbackAdapter` は renderer/model、camera、WP152 migration、将来の
behavior adapter を aggregate protocol へ接続する型付き境界であり、prepare 以外の
callback 型を `noexcept` に固定する。staged publication と inverse-token publication を
明示的に区別し、後者だけに publish fault injection を許可した。

## 3. E-C2 transform / reparent

- `set_component_value(transform)` は staged authoring local TRS を更新し、runtime local と
  world を同じ commit に含める。runtime projection は `local_trs` と `world_trs` を別 field
  で返し、world を authoring document へ暗黙 write-back しない。
- 合成は `world.pos = parent.pos + parent.rotation * (parent.scale * local.pos)`、
  `world.rotation = parent.rotation * local.rotation`、
  `world.scale = parent.scale * local.scale` とし、root、子、孫の順で closure を計算する。
- preserve-local は local TRS を不変にして parent だけを変更する。preserve-world は旧
  world と新 parent world から local を逆算し、再合成結果との一致まで preflight する。
- `TransformCycle`、`TransformZeroParentScale`、`TransformNonFinite`、
  `TransformUnrepresentable` を個別の stable code とし、error に
  `/scenes/<scene>/objects/<name>` path を保持する。

# WP131 OpenXR view / reference-space 規約 実装報告

日付: 2026-07-17
対象: XR2a.2 / WP131

## 結論

WP131 を実装した。OpenXR adapter に、設計で凍結された view 行列合成、非対称
RH_ZO projection、参照空間の `STAGE -> LOCAL_FLOOR -> LOCAL` 選択を追加した。
flat camera API、renderer core、main loop、input state には変更を加えていない。

`LOCAL` fallback は床原点として扱わない。選択結果は `get_status.xr` に
`reference_space="LOCAL"`、`floor_semantics="floor_not_guaranteed"`、
`floor_level_guaranteed=false`、`applied_floor_offset_m=0.0` として露出する。
床高補正は実装しておらず、`LOCAL` を `STAGE` と呼び替える経路もない。

## 実装

### view / projection adapter

`src/core/openxr/openxrviewspace.{hpp,cpp}` に pure adapter を追加した。座標系は
OpenXR / Pelican 共通の RH、+Y up、-Z forward、metres、外部 quaternion `xyzw` である。
各 view の計算順は設計 §6 と一致する。

```text
world_from_stage = inverse(active_camera_view_at_frame_start)
stage_from_eye   = rigid_transform(XrView.pose)
world_from_eye   = world_from_stage * stage_from_eye
view             = inverse(world_from_eye)
camera_position  = translation(world_from_eye)
projection       = asymmetric_RH_ZO(XrView.fov, z_near, z_far)
```

`l=tan(angleLeft)`, `r=tan(angleRight)`, `d=tan(angleDown)`,
`u=tan(angleUp)` とした column-major 行列の非ゼロ要素は次のとおりである。

```text
P[0][0] =  2 / (r - l)
P[1][1] = -2 / (u - d)
P[2][0] =  (r + l) / (r - l)
P[2][1] = -(u + d) / (u - d)
P[2][2] = -far / (far - near)
P[2][3] = -1
P[3][2] = -(far * near) / (far - near)
```

これは RH_ZO で、`z=-near` を NDC z=0、`z=-far` を NDC z=1 に写す。
Pelican の positive-height Vulkan viewport に合わせ、上端を NDC y=-1、下端を
NDC y=+1 に写す clip-Y 符号も fixture で固定した。

### reference space

session 作成後に `xrEnumerateReferenceSpaces` を二段階で呼び、次の順序で利用可能な
最初の空間を選択する。列挙数が二回目の容量を超える不正な runtime 応答も拒否する。

| 選択 | status 名 | floor semantics | floor level | 補正 |
|---|---|---|---:|---:|
| `STAGE` | `STAGE` | `stage_floor` | guaranteed | 0 m |
| `LOCAL_FLOOR` | `LOCAL_FLOOR` | `estimated_floor` | guaranteed | 0 m |
| `LOCAL` | `LOCAL` | `floor_not_guaranteed` | not guaranteed | 0 m |

Pelican は OpenXR API 1.0 を要求するため、runtime が
`XR_EXT_local_floor` を広告した場合だけ同 extension を instance 作成時に有効化する。
広告されない extension は要求しない。OpenXR inactive 時の `get_status.xr` は
`active=false`、`reference_space=null`、`floor_semantics="not_applicable"`、
`floor_level_guaranteed=false`、`applied_floor_offset_m=null` を返す。

## CPU fixture

手計算した固定値を使う5 fixture を追加した。実装関数から expected 値を生成していない。

1. identity pose: identity view、camera position `(0, 0, 0)`。
2. IPD 64 mm: eye x を `-0.032 / +0.032 m`、view の逆平行移動を
   `+0.032 / -0.032 m`、眼間距離を `0.064 m` に固定。
3. yaw +90 degree: quaternion `(0, 0.70710678, 0, 0.70710678)` と
   `world_from_stage` translation `(1, 2, 3)` の合成後 view 全要素を固定。
4. asymmetric FOV: tangent `l=-0.5, r=1.0, d=-0.25, u=0.75`、
   near `0.1`、far `100` の行列要素と左右上下・near/far NDC 境界を固定。
5. reference space: `STAGE -> LOCAL_FLOOR -> LOCAL` 優先順位と、`LOCAL` の
   floor non-guarantee / offset 0 m を固定。

既存の discovery / session / composition / RPC fixture も更新し、extension の条件付き
有効化、参照空間列挙、選択結果、inactive status の contract を検証した。

- golden fixture / baseline は変更していない。

  Vulkan/golden、OFF build の各 gate は完了した。

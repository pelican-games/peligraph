# WP109 実装・検証報告 — S2D-2 side-scroller vertical slice

日付: 2026-07-16
対象: `design_2d_game_layer.md` v2.4 §7-2 / §9 S2D-2

## 結論

WP106 の sprite/strict pixel/flipbook と WP107 の ordered shapeCast/MTD/provider
V2 を、標準ユーザー空間 `platformer::moveAndSlide` で接続した。入力、fixed-step、
接地、斜面、one-way、event を同じ side-scroller 1 面で実行できる。controller は
Jolt/Builtin の内部を includeせず、公開 query surface だけに依存するため、ゲームから
パージ・コピー改造・独自 provider/query への交換が可能である。

## 公開契約

- `src/core/userpublic/platformer/charactercontroller2d.hpp`
- `moveAndSlide(shape, delta, ordered_all_hit_callback, filter, settings)` が本体
- `moveAndSlide(GameContext&, ...)` は `shapeCastAll` へ渡すだけの adapter
- 結果は移動後 shape、要求/適用/残差 delta、contact 列、ground/wall/ceiling、
  iteration-limit flag
- XY 固定、最大 8 iteration、trigger は既定非 blocking、one-way は上からの接近だけ
- orientation と shape dimensions は変更しない

エンジンが保証するのは query data と stable identity/all-hit 順で、controller の
slope/one-way/dynamics policy はユーザー空間にある。このため、将来 Jolt rigid body や
GPGPU simulation を追加しても別 capability として併存できる。

## 縦切り

`projects/sprite_demo` を WP109 dogfood project とした。

- A/D: 水平移動、Space: jump、S: one-way drop-through
- capsule player + floor + walkable slope + one-way platform + wall
- 公開 `FlipbookClip` で歩行 frame/flip を更新
- 接地遷移で `PlayerLanded` を emitし、次 frame に購読
- gravity/velocity/controller policy はすべて project code

game DLL から custom event を emitした際に event registerer の内部 symbol export 漏れが
判明したため、必要な 2 symbol を公開し、`public_api_link_fixture` に emit probe を追加した。

## Fixture

`test/platformer_controller_test.cpp` は次を覆う。

1. 高速 capsule と薄床の tunneling
2. 壁への接近後の slide
3. walkable slope と steep slope の分類
4. one-way の下から通過、上から接地、drop-through
5. zero-delta initial overlap の決定的回復
6. 240 fixed-step の side-scroller 入力 replay 2 回について、全 pose の float bit trace と
   landing event 列の完全一致
7. 非 finite/範囲外設定と callback の公開 API validation

## 検証結果

- Debug 全ターゲット build: 成功
- Debug CTest: **全 402 件で失敗 0**(401 pass)。Windows の symlink 権限に依存する
  既知の PathResolver 1 件だけ skip
- controller 単体: 7 test case / 36 assertion 成功
- event layer 回帰: 2 test case / 5 assertion 成功
- public game DLL link fixture: controller API と custom event emit を含めて成功
- `PELICAN_WITH_PHYSICS=OFF`、provider-only、Jolt の各 `pelican_core` build: 成功
- WP109 project DLL build + 960x540/60fps headless 120 frame: 成功。
  game logic DLL、初期化、landing event を確認し、strict pixel downgrade は 0

## 意図して残した境界

step-up、coyote time、moving platform、TileMap、物理 trigger event、剛体 dynamics は
WP109 の最小 controller 契約に含めない。ゲーム固有 policy または将来の独立 capability
として、実需と測定結果を得てから追加する。

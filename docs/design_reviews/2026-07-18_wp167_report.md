## 3. activation / publication boundary

```text
frame N
  acceptance gate
    ├─ replay / golden                         -> reject
    └─ behavior callback / DLL reload / G2    -> stable reject
          |
          v
  journal prepare
    ├─ handle + attachment_seq を一度だけ確定
    ├─ authored document を stage
    └─ behavior params/instance を temporary decode + validate
          |
          v
  E-RPC aggregate transaction (observer-free publication interval)
    ├─ existing adapters publish
    ├─ behavior junction publish (最後)
    |    ├─ attach: inactive, activation_delay=1
    |    ├─ remove: onDestroy(entity は alive) -> arena erase
    |    └─ set: prepared Params を live Params と no-throw swap
    └─ document publish -> commit revision
          |
          +-- frame N の onEvent/onUpdate
              attach は不可視 / set の新 params は可視 / remove は不可視

frame N+1 activation boundary
  activation_delay=0 の attach -> onInit exactly once -> onEvent/onUpdate
```

prepare 中の decode、schema、owner、stale target のどれかが失敗した場合は document と arena の
双方が未変更のまま終わる。behavior junction は aggregate の最後に置き、publish 自体を
allocation-free/no-throw にしたため、その後は既存の no-throw document publication だけが残る。

## 4. 主な変更点

- `behaviorarena` に editor edit batch の prepare/publish token、runtime identity 予約、index shift、
  delayed activation、pre-destroy remove、prepared params swap を追加した。
- behavior registerer に type-erased temporary params と prepare/apply/destroy 関数を追加し、
  `Params` の nothrow swap を登録時 static assertion にした。
- editor journal/service/runtime factory に behavior canonical validation、exact attachment target、
  stable write domain、raw inverse、identity resolver、G2 gate、runtime owner/generation query を追加した。
- Inspector は同型 attachment を index/handle 付きの一意 ID で描画し、behavior params でも
  WP164 の schema widget を再利用する。pending は read-only raw JSON と badge を描画する。
- frozen schema header、`editorprojectiontransaction`、projection adapters の本体は変更せず、
  既存 junction interface のみを利用した。

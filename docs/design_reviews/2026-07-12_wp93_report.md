# WP93 実装レポート — UI U2 対話ウィジェットと E1 emit・RPC 再生

日付: 2026-07-12
ブランチ: `agent/wp93-ui-u2`

## 結果

WP93 の作業リスト 6 項目を実装した。U1 の quad 描画へ同梱 bitmap font の
label/button を追加し、U0 の capture 状態機械を実ランタイムへ接続した。
hover/pressed は UI-local command として全 ordered event の処理後に一括
commit され、`emit` は EventPayloadSchema でロード時検証された payload を
E1 pending queue へ積むため、game handler への配送は次フレームになる。

## 実装内容

- `BitmapFont` を追加し、`engine://debug_text_font.json/png` の ASCII 32〜126、
  atlas bounds、重複、整数 advance を検証する。OS font は使用しない。
- label は同梱 advance で intrinsic size を算出し、nearest sampler の glyph
  quad を生成する。button は solid quad と中央揃え label を描き、base / hover /
  pressed の linear RGBA8 色を持つ。
- `UiModule` に世代付き WidgetArena、安定 traversal、InputRouter、
  UiCommandBuffer を統合した。pointer routing は ImGui の後、Actions の一回確定
  より前に行い、UI hit/capture frame は pointer input を Actions からマスクする。
- UI feature 有効時だけ loop setup で CPU runtime を生成する。これにより最初の
  render より前の RPC click も失わず、feature 非参照時の purge gate は維持する。
- `on_click` / `on_drag_start` / `on_drag` を E1 by-name emit へ接続した。
  `static` / `stable_id` / `drag_delta_ui` / `widget_value(value|checked|text)` を
  JSON payload に構築する。Typed(empty) は厳密な空 object、Payloadless は payload
  省略で発行する。Opaque binding と Payloadless の `fields` 指定は
  `no_payload_event` のまま拒否する。
- debug_text も同じ `BitmapFont` table reader を使うようにし、従来の vertex/
  pipeline は維持した。既存 debug_text Golden と最終 RGBA8 hash は変更していない。

## 決定性 fixture

`ui_foundation_test` の U2 gate は次を検査する。

- pointer down 後に pressed 色が同フレームの draw batch へ反映されること。
- release/click 後も semantic が pending のままで、次の E1 freeze で初めて
  deliver_now に移ること。
- `stable_id` と static range 付き field が typed event instanceへ一致すること。
- 旧 debug_text の独立レイアウト手順と共通 BitmapFont path で同じ複数行 fixture
  を atlas から RGBA8 rasterize し、`tolerance 0` の byte-exact 一致になること。

`ui_u2_rpc_replay_player` は 160x90 の自己完結 project で次を検査する。

1. RPC ordered mouse move/down/up で click event を発火し、同フレームの status は
   不変、次フレームに seed `9307` へ変わる。
2. capture 外へ奪わず同一 owner の drag delta `[10,0]` を発行し、次フレームに
   seed `9310` へ変わる。
3. click + drag の ordered InputEvent 列を `pelican.input_seq` v1 に収録する。
4. 新規 process 2 回で replay し、recording run を含む 3 枚の最終 capture PNG が
   byte 一致する。

押下中の RPC capture は
`build_wp93/test_artifacts/ui_u2_rpc_replay/rpc_click_pressed.png` に生成した。
同梱 glyph の `CLICK` / `DRAG` と、押下中の暗色 button が表示されることを実画像で
確認した。

## Emit エラー互換

U0 の `document_emit_errors.json` を変更せず実行し、次の 7 分類を既存 code と
1:1 で維持した。新しい error code は追加していない。

1. `unknown_event`
2. `unknown_source` / `unknown_widget_value_path`
3. `type_mismatch`
4. `range_violation`
5. `required_missing`
6. `unknown_field`
7. `no_payload_event`

U0 の semantic fixture 3 段 gate（schema/coverage、semantic validator、expected
equality）は全てそのまま green である。

## Golden と互換ゲート

- Golden directory を `ui_u2` 1 件追加し、件数 REQUIRE を 22 → 23 に更新した。
- `ui_u2` は 16x16 の button + 同梱 glyph を描き、tolerance は
  `average=0.0 / max=0`。
- Golden `23/23` 成功、SKIP 0。
- 既存 22 case の final RGBA8 SHA-256 は全て変更なし。`ui_u2` の hash と renderer
  trace / canonical frame-plan trace だけを追加した。
- debug_text の旧 Golden/hash は byte-exact で維持した。色 baseline の versioned
  更新は行っていない。

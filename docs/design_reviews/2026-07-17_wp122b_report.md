# WP122b 完了レポート — M-INST1: material 別 absolute override

日付: 2026-07-17

対象: `agent/wp122b-inst1`

判定: **完了**

## 結論

WP122 の instance 単位 multiplier record を変更せず、その横に
`(instance identity, source glTF material index)` 単位の版付き absolute override
を追加した。draw command まで source material index を保持し、standard / Surface V1 /
OpenPBR が共通 shader accessor で draw 中の material identity と照合する。

`ModelTemplate` には source material index で直接引ける immutable な初期
base color / emissive / UV transform metadata を追加した。これにより WP123 は初期成分が
0 の material についても multiplier へ除算せず、
`Base + Σ((Target - Base) × weight)` を CPU で絶対値へ解決して publish できる。

凍結 `src/core/userpublic/animation/abi_v1.hpp` は変更していない。既存
`material_instance_override` の RGBA8 SHA-256 も
`2015a61d5aadb1cd5d978d5896b430c5d5cb12f014dbf60effad24b22c7009e0`
のままである。

## storage と publish 契約

### WP122 v1 互換経路

- `PublishMaterialInstanceOverrideDescV1`、`MaterialInstanceOverrideFrame`、
  `MaterialInstanceOverrideGpuData` は field / size / 意味を変更していない。
- set 3 binding 9 の 80-byte / instance record は従来どおり instance 全 material 用の
  multiplier である。
- v2 absolute record に該当 field がない場合だけ v1 multiplier を適用する。該当 field が
  ある場合は absolute を優先するため、0 成分を含む target を除算なしで表現できる。

### material 別 absolute v2

renderer 内部 descriptor として `PublishMaterialInstanceAbsoluteOverrideDescV2` を追加した。
version は 2 で、instance handle / monotonic frame revision / source material index / value
mask / absolute base-emissive-UV target / reset-discontinuity flag / reserved を持つ。

CPU storage は `MaterialInstanceAbsoluteOverrideKey`、すなわち
`(instance identity, source material index)` を key にする。frame は instance generation、
source material index、current / previous revision と current / previous absolute values を
保持する。全 instance 合計の active record 上限は 4096 で、超過は既存 status
`out_of_memory` とする。

GPU storage は v1 と分離した。

| binding | record | 内容 |
|---:|---|---|
| set 3 / 10 | 16-byte / instance | dense record の offset / count、instance generation |
| set 3 / 11 | 80-byte / active override | absolute base / emissive / UV、mask、source material index、revision |

CPU map を instance identity、source material index 順に deterministic に pack し、header の
offset / count から shader が対象 instance の短い範囲だけを検索する。record は固定 4096
容量を一度確保し、1000 回の同一 key 更新で entry / buffer は増えない。

publish は descriptor size/version、reserved、instance identity/generation、source material
metadata の存在、revision、mask/flag、全 float の finite 性、容量を事前検証する。不正入力は
CPU frame と GPU record の双方を変更しない。

## source material identity と shader accessor

`ModelTemplate::MaterialPrimitives` に source glTF material index を残し、skinned / VAT 用に
生成した global material variant でも元 index を引き継ぐ。USD material binding の regroup
も global material ID だけでまとめず、source index を保つ単位で行う。

`RenderCommand` / `DrawIndirectInfo` は global material ID と source material index の両方で
grouping する。material push constant は従来の global `materialIndex` に
`sourceMaterialIndex` を additive に続けた。fragment accessor は flat instance identity と
この source index で v2 record を照合する。

base color absolute factor は vertex stage で glTF material factor と置き換えるため、初期 factor
が 0 でも vertex color / texture 情報を失わない。Surface V1 の user hook にも解決済み absolute
factor が入る。emissive と UV は fragment stage で同じ record を使う。absolute record がない
draw / field は従来の演算順と v1 multiplier に戻る。

## immutable 初期値 metadata

`ModelTemplate::material_initial_values` は
`std::shared_ptr<const SourceMaterialInitialValueTable>` であり、model generation に属する
immutable table とした。table は source material index で直接 index でき、各 entry は次を持つ。

- base color factor RGBA
- emissive factor RGBA（`KHR_materials_emissive_strength` 適用後）
- UV offset / scale / rotation（`KHR_texture_transform`、未指定は identity）

global `MaterialContainer` record や hot-reload mutable state から初期値を逆算しない。fragment load
でも source GLB の全 material metadata を保持するため、VRM bind index の座標を失わない。
fixture は base/emissive が 0 の material 0 と KHR UV 初期値を decode し、table の値を直接検査する。

## temporal history、remove、reload

- 初回 publish は `previous = current`。
- render 終端の `advanceMaterialOverrideHistoryAfterRender()` で v1 と v2 の current を previous
  へ進める。
- reset/discontinuity flag と `resetTemporalHistory()` は v2 も `previous = current` に畳む。
- remove / clear は該当 key と GPU header を消す。
- model rebuild は instance identity を維持したまま generation を進め、v1/v2 state と GPU
  header を resetし、immutable table を replacement generation のものへ差し替える。
- reload 前 handle の v2 publish は `stale_generation` になる。

## WP123 への引き継ぎ

1. WP123 resolver は bind の source material index で
   `ModelTemplate::material_initial_values` を引き、各 parameter を
   `Base + Σ((Target - Base) × weight)` で一つの absolute target に解決してから v2 sink へ
   publish する。初期 0 を multiplier へ変換しないこと。
2. 一つの expression tick で複数 material key に同じ revision を publish できる。各 key は
   monotonic revision を独立検証する。morph / material / UV を跨ぐ atomic multi-sink transaction は
   引き続き WP123 の責務である。
3. base color / emissive / texture transform 以外の MToon 専用 color type は WP122b v2 に
   混入していない。確定どおり WP123 v1 で名前入り WARN + bind 単位 skip とする。
4. seek / discontinuity は既存 temporal reset 境界と v2 flag を共用する。model reload 後は新しい
   generation と immutable table へ bind を再解決する。
5. v2 descriptor は renderer 内部面である。WP123 の公開 application service は additive な別
   header / entry point とし、凍結 `animation/abi_v1.hpp` を変更しない。

以上により、WP123 の blocking 監査 1・2 と停止質問 1 を解消した。

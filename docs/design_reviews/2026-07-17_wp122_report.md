# WP122 完了レポート — M-INST0: per-instance material override ABI

日付: 2026-07-17
状態: **完了**

## 結論

`MaterialInstanceOverrideBlock` を material template / per-material SSBO から分離し、
model instance identity と generation に属する renderer 内部 ABI として実装した。
v1 は base color factor、emissive factor、UV offset / scale / rotation を持ち、
standard と Surface V1/OpenPBR の双方が同じ surface 非依存 accessor を通して読む。

共有 material record は publish、history advance、reset、model reload、1000 回更新の
いずれでも byte 不変である。凍結済み公開 `src/core/userpublic/animation/abi_v1.hpp` は
変更していない。

## 実装

### instance block と publish 契約

`PolygonInstanceContainer` に次を追加した。

- `PublishMaterialInstanceOverrideDescV1`: `struct_size` / `version`、
  `Animation::InstanceHandle`、monotonic `frame_revision`、値 mask、reset/discontinuity flag、
  reserved field を持つ renderer 内部 descriptor
- `MaterialInstanceOverrideFrame`: instance identity / generation と current / previous の
  値・revision を保持
- `MaterialInstanceOverrideGpuData`: 16-byte alignment、80 bytes/record

GPU record は以下の固定配置である。

| offset | field | 内容 |
|---:|---|---|
| 0 | `base_color_factor` | RGBA multiplier |
| 16 | `emissive_factor` | RGBA multiplier |
| 32 | `uv_offset_scale` | `offset.xy`, `scale.xy` |
| 48 | `uv_rotation_reserved` | rotation radians + reserved |
| 64 | `metadata` | mask、generation、revision low/high |

publish は descriptor version、reserved、instance identity、generation、revision、mask、flag、
全 float の finite 性を先に検証する。不正入力は CPU frame と GPU record のどちらも変更せず、
同一または古い revision も reject する。検証後に 1 record だけを書き、CPU state を
`insert_or_assign` するため、毎 frame 更新で entry や GPU resource は増えない。

CPU state は override が一度も publish されていない instance には作らない。GPU buffer は
container ごとに一度だけ固定確保・全ゼロ初期化し、instance の配置だけでは書き込まない。
したがって override なし instance の追加に伴う state allocation / upload はゼロで、
accessor は mask 0 を identity として扱う。remove、clear、model rebuild は該当 GPU record も
ゼロ化し、instance ID 再利用時に値が残らない。

### descriptor set と pass 境界

新規 storage binding は `PELICAN_SET_FREE` (set 3) の binding 9、fragment stage である。
material 本描画用に static/skinned の descriptor layout/set を別に作り、既存の
deformation-only layout/set は shadow と velocity 用に維持した。この分離により、
material override を読まない pass の pipeline layout を変更していない。

material template の `MaterialGpuData`、texture descriptor、material revision は書き換えない。
テスト用 byte snapshot はこの不変条件を record 全体で検査するためだけに追加した。

### standard / Surface V1 / OpenPBR 経路

static、skinned、VAT、Surface V1 vertex shader は `gl_BaseInstance` を flat varying として
fragment shader へ渡す。`pelican_material_instance.glsl` はその index で block を読み、
次の共通関数を提供する。

- base color / emissive の identity-aware factor と apply
- `offset + rotation * (uv * scale)` の UV transform

standard fragment は base color、normal、metallic-roughness、emissive の全 texture sample に
変換後 UV を使い、base color と emissive に instance factor を適用する。

Surface V1 template は変換後 UV を `PelicanSurfaceInputV1` と標準 texture sample の双方へ渡し、
user surface hook の後に color factor を適用する。OpenPBR direct lighting は parameter を再読して
override を失わないよう、template が確定した canonical `surface.base_color` を消費する。
これにより standard、toon/custom Surface V1、OpenPBR のいずれにも OpenPBR 固有の
instance ABI を持ち込まず、同じ accessor 境界で動作する。既存 OpenPBR coat golden の
RGBA8 hash も不変だった。

### N / N-1、reset、reload

初回 publish は current を previous にも複製する。render 終端の
`advanceTemporalHistoryAfterRender()` で current を previous へ進め、reset/discontinuity flag と
`resetTemporalHistory()` はその場で previous=current とする。material 値は velocity consumer を
持たないため previous GPU buffer は作らず、N/N-1 application state を CPU 側で保持する。

model rebuild は WP121 と同じ animation generation を進め、override state と GPU record を
default へ戻す。旧 handle の publish は `stale_generation` になる。通常の reset は値を消さず、
history だけを current に畳む。

## Golden と fixture

`material_instance_override` を 1 件追加した。同一 model/material template を共有する二体へ、
同じ revision で異なる base/emissive/UV override を publish し、別 tint で描画する。

- golden 件数: `PELICAN_WITH_VAT=ON` は **44**、OFF は **43**
- 既存 expected PNG の変更: **0**
- RGBA8 hash fixture: 既存 key は全一致、新規 key 1 件だけ additive 追加
- renderer execution trace / canonical plan trace: 新規 key/行だけ additive 追加
- 新規 RGBA8 SHA-256:
  `2015a61d5aadb1cd5d978d5896b430c5d5cb12f014dbf60effad24b22c7009e0`

## WP123 / S1b への引き渡し

1. 本 descriptor は renderer 内部面であり、そのまま公開 ABI にしない。S1b は versioned
   application service を additive に追加し、凍結 `abi_v1.hpp` を変更しないこと。
2. VRM expression resolver は model/material template を複製せず、instance handle、generation、
   monotonic revision と解決済み multiplier/UV transform をこの sink へ渡すこと。
3. pose/palette、morph、material/UV の atomic multi-sink commit は WP123 の責務である。
   各 sink の個別 publish は atomic reject できるが、複数 sink を跨ぐ transaction は本 WP では
   導入していない。全 sink の事前 validate/stage 後に同一 revision で publish する境界が必要。
4. seek、teleport、source discontinuity は reset/discontinuity flag と既存 temporal reset 境界を
   共用すること。reload 後は新 generation へ再解決し、旧 handle を再利用しないこと。
5. UV rotation は radians、変換順は scale → origin 回転 → offset である。別 pivot が必要なら
   v2 の additive field とし、v1 の意味を変更しないこと。

# WP135 — XR4: VRM キャラデモ project（flat 先行）完了報告

## 結果

`projects/vrm_xr_demo/` に、flat と OpenXR で同じ入力・animation graph・
VRM application 経路を使う自己完結型デモを追加した。コミット済み VRM は
fixture writer が生成する決定的な VRM 1.0 で、全必須 humanoid bone、
Idle/Walk/Run/Jump、happy/angry/sad/relaxed、expression lookAt、
firstPerson `auto` を含む。

![flat 実行時の VRM キャラクター](../../projects/vrm_xr_demo/screenshot.png)

## 実装

- `movement.anim_graph.json` とゲーム DLL の同一 graph で、speed による
  Idle/Walk/Run の 1D blend と、優先度 100 の Jump interrupt を実装した。
- keyboard、gamepad、Touch を `move`、`jump`、`expression_next`、`look`
  の共通 action に束ねた。Touch は公開命名の `aim_left/right`、
  `grip_left/right` も宣言し、`head` は binding せず synthetic head を使う。
- flat では authored camera を lookAt の基準にし、矢印／右 stick で視線を
  オフセットする。XR では `xrLocateViews` 由来の synthetic head pose を優先する。
- flat view は third-person の全身、XR eye view は first-person visibility を使い、
  head-weighted triangle を除外する。
- render feature は空配列で、TAA、projection jitter、velocity、history、UI を
  一切要求しない。WP133 の XR graph 除外表に抵触しない。
- RPC fixture は idle、W、Jump、表情切替、lookAt を2回実行し、各 capture の
  run 間 byte 一致と stage 間差分、状態ログを検証する。

## 使用した公開面（エンジン変更ゼロの証明）

project のゲームコードが include するのは `src/core/userpublic` から配布される
次の公開 header だけである。

- `animation/animgraph.hpp`: `parseDocumentV1`、`EvaluatorV1::bind`、
  `setParameter`、`prepareTick`、`getStatus`
- `animation/abi_v1.hpp`: animation service negotiation、named sink／instance 解決
- `animation/vrm_application_v1.hpp`: application service negotiation、
  `SetExpressionInputDescV1` による preset weight と lookAt 入力
- `gamecontext.hpp` / `gamesystem.hpp`: action button／axis／pose、時刻、ログ、
  `PELICAN_REGISTER_SYSTEM`

firstPerson の per-view 選択、Touch pose、synthetic head、XR activation は既存の
公開契約と project JSON を利用した。`src/` 以下のエンジン／OpenXR adapter は
変更していない。

## 実行方法

flat の build／操作方法と実 VRM 1.0 への差し替え方法は
`projects/vrm_xr_demo/README.md` に記載した。Quest 3 / Quest Link では、Meta を
active OpenXR runtime にして次を実行する。

```powershell
pelican_player.exe --project projects/vrm_xr_demo --xr on --input-profile touch
```

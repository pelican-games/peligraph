# WP199 完了レポート — Python opt-in development boundary

日付: 2026-07-24

## 結果

Pythonを「エンジン／ゲーム／通常configureの依存」から外しつつ、JSON・file・process
orchestrationに適したCI gateとfixture生成toolは開発専用資産として保持した。
`.py`を0件にすることは目的にせず、Pythonを使うlaneだけを明示opt-inにした。

`PELICAN_PYTHON_TESTS`の既定を`AUTO`から`OFF`へ変更した。通常の
`BUILD_TESTING=ON`構成でもPythonを探索せず、C++/CMakeテストだけを登録する。
手元の任意利用には`AUTO`、完全CIには既存どおり`ON`を使う。

OpenXR-SDK-Sourceは`BUILD_FORCE_GENERATION=OFF`でも上流CMakeがPythonを任意探索する。
Pelicanはchecked-in生成済みsourceを使うため、OpenXR追加をfunction scopeへ隔離し、
そのscope内だけ`CMAKE_DISABLE_FIND_PACKAGE_Python3=TRUE`とした。呼び出し元の
Python package policyは変えないため、後段の明示ONテストは通常どおりPythonを要求できる。

## 意図的に残すもの

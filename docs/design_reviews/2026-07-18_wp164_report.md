## Blocker 1: query schema に enum の選択肢がない

WP164 は、query 応答の schema fields（型/range/**enum**）だけから widget を
生成し、`StructFieldType::Enum` は combo とすることを要求している。しかし現在の
公開 query surface には enum のラベル一覧が残らない。

1. 宣言時の `DefaultedStructField` は `enum_values` を保持している
   (`src/core/userpublic/details/schema/structfieldschema.hpp`)。
2. query が保持する `StructFieldSchema` は `name`、`type`、`range`、`unit` の
   4 項目だけである。同 header の `materializeStructField()` で `enum_values` は
   `StructFieldSchema` へ移されず失われる。
3. `EditorCommandService` の `schemaFieldJson()` も `name`、`type`、任意の
   `range` / `unit` だけを出力する。
4. そのため UI adapter が受け取る `EditorComponentQueryResult::schema_fields`
   からは、例えば `light.type` の `directional / point / spot` を復元できない。

現在値だけを唯一の combo 項目にする、field/component 名で選択肢を手書きする、
codec 実装を ImGui から参照する、のいずれも「query 応答が正」「新 component が
来てもインスペクタ側 0 行」「component 別の手書き UI 禁止」を満たさない。
また、解消に必要な schema header または `editorcommandservice` の変更は今回の
禁止領域である。

## Blocker 2: interactive UI 用 service は read-only

`ImGuiSystem` が所有する service は
`makeInteractiveEditorAssetQueryService()` で構築される。この factory は
`document`、`current_scene_id`、`assets` だけを設定し、`runtime_query` と
`EditorEditRuntimeDependencies` を設定しない。したがって同 service に対する
`openEditorSession` / `edit` / `undo` / preview / poll は
`editor edit service is unavailable` となる。

一方、production の runtime query、projection、preview、gate、commit hook の
composition は `rpcserver.cpp` の `EngineRpcEndpoint::Impl` と anonymous namespace
内 helper に閉じている。UI と RPC が同じ production composition を再利用できる
公開 factory はない。

これを解消する候補は次のどちらかだが、現 goal からは選べない。

- communication 層へ共有 production factory を切り出し、RPC と ImGui の双方が
  それを使う（`rpcserver` の変更禁止と衝突する）。
- `editorassetqueryruntime.cpp` に RPC 側の runtime binding / projection composition
  を複製する（「ImGui panel 新設 + fake-service test」の排他範囲を越え、RPC/UI
  の validation/commit trace が将来分岐する）。

   `StructFieldSchema` / query result に enum label 一覧を追加してから WP164 を
   再開する、という依存順でよいか。そうでない場合、今回どの禁止領域の additive

   `EngineRpcEndpoint` と ImGui の両方が同じ factory を消費する形である。このための
   `rpcserver.cpp` の配線変更を許可するか。

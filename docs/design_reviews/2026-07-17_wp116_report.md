# WP116 M-PBR0a — OpenPBR 表現 / routing ABI 実装レポート

## 結論

`design_usd_openpbr.md` v2.1 §1-1 と再レビュー条件 `M-PBR0a-STATE` に従い、
OpenPBR を後続 WP で実装するための additive な表現・routing・primitive binding ABI を実装した。
`pelican.material` は宣言済み surface texture の per-material 差し替えと
`alpha_mode` / `double_sided` routing を表現でき、lowering は六つの固定 state variant を検証して
lighting hook の forward pass へ送る。別 artifact の
`pelican.material_bindings` v1 は USD prim/subset path、GLB mesh/primitive index、
Pelican material 名、routing の安定対応を持ち、model template と model asset loader が
whole-model 契約として消費する。

本 WP は ABI のみである。OpenPBR surface/BRDF 本体、USD/MaterialX/glTF からの数値写像、
六つの production wrapper は M-PBR0b 以後へ残した。`PelicanSurfaceV1`、G-buffer、
既存 material の dump/image golden は変更していない。

OpenPBR input 名の照合元は公式 [OpenPBR v1.1.1](https://github.com/AcademySoftwareFoundation/OpenPBR/tree/v1.1.1)
（tag commit `f8d6d947dfae4c9b599965a86c22826ea7a8dbfb`）の
`reference/open_pbr_surface.mtlx` である。M-PBR0b の exact pin、unit/range/default/
colorspace/channel 数表は、この ABI の上へ別途追加する。

## OpenPBR 対応 input の置き場

ここでいう「custom texture」は新しい texture 宣言ではない。M-PBR0b の wrapper が
`.surface` header に宣言する slot を `pelican.material.textures` が差し替える場所である。
constant 値は surface param、空間変化する接続はその宣言済み texture slot、BRDF 評価は
`pelican_lighting_v1` が生成 param/texture accessor を直接読む。具体的な slot 名と数値写像は
M-PBR0b の責務であり、M-PBR0a で先取りして固定しない。

| OpenPBR 1.1.1 input / import metadata | surface param | custom texture | render state / routing | lighting |
|---|---|---|---|---|
| `base_weight`, `base_color`, `base_diffuse_roughness`, `base_metalness` | constant 値 | 接続がある input の宣言済み color/data slot | なし | lighting hook が base lobe を評価 |
| `specular_weight`, `specular_color`, `specular_roughness`, `specular_roughness_anisotropy`, `specular_ior` | constant 値 | 接続がある input の宣言済み color/data slot | なし | lighting hook が dielectric/specular lobe を評価 |
| `coat_weight`, `coat_color`, `coat_roughness`, `coat_roughness_anisotropy`, `coat_ior`, `coat_darkening` | constant 値 | 接続がある input の宣言済み color/data slot | なし | lighting hook が単一 coat layer を評価 |
| `emission_luminance`, `emission_color` | constant 値 | 接続がある input の宣言済み color/data slot | なし | lighting hook の forward 出力へ加算 |
| `geometry_normal`, `geometry_coat_normal` | geometry default は surface input、scale 等の補助値だけ param | 接続時は role=data の宣言済み normal slot | なし | lighting hook が base/coat normal を使用 |
| `geometry_tangent`, `geometry_coat_tangent` | geometry default は vertex/surface input | M-PBR0b が接続を採用する場合だけ宣言済み data slot | なし | anisotropy の方向として lighting hook が使用 |
| `geometry_opacity` | constant opacity | 接続時は宣言済み data slot | `alpha_mode` が OPAQUE/MASK/BLEND wrapper を選択 | MASK discard 又は BLEND 出力の alpha source |
| glTF/import `alphaMode` | なし | なし | material/binding の `routing.alpha_mode` | OPAQUE/MASK は `forward_opaque`、BLEND は `forward_transparent` |
| glTF/import `alphaCutoff` | MASK wrapper の float `alpha_cutoff`（必須） | なし | MASK は opaque blend + depth write | 境界は `alpha >= alpha_cutoff` を keep、未満を discard |
| OpenPBR/glTF `doubleSided` | なし | なし | material/binding の `routing.double_sided`; false=`cull=back`、true=`cull=none` | front/back lighting の wrapper 選択に伝播 |

設計が M-PBR0b v1 subset とした base/specular/IOR/coat 一層/emission/normal/alpha だけを
上表の対象とした。transmission、subsurface、fuzz、thin film、`geometry_thin_walled` 等を
「対応済み」とはしていない。

## ABI 追加一覧

### 1. `pelican.material` の additive key

既存 schema/version は `pelican.material` v1 のまま、material entry に次を追加した。

```json
{
  "name": "imported_mask",
  "surface": "project://openpbr/mask_double.surface",
  "values": {"alpha_cutoff": 0.5},
  "textures": {
    "opacity_map": "project://textures/leaf_opacity.png"
  },
  "routing": {
    "alpha_mode": "mask",
    "double_sided": true
  }
}
```

- `textures` は object で、key は選択済み `.surface` に宣言された texture 名だけを許す。
  値は string の project/engine reference だけであり、surface 側の role、view、binding、
  semantic dummy は変えない。未宣言名、型不一致、無効参照は material/texture 名入り hard error。
- `params` 宣言は従来どおり禁止し、値の差し替えは `values` だけを使う。
- `routing` は exact key `alpha_mode` (`opaque|mask|blend`) と boolean `double_sided` を持つ。
  任意の material-level cull/blend override は導入していない。
- `LoweredMaterial` は解決済み texture reference と routing を保持する。binder の新 overload は
  各 reference と宣言 role を `GlobalTextureId` に解決し、失敗を material/texture/reference 名で包む。
- hot reload の non-values signature に texture override/routing を含め、これらの変更を
  values-only reload と誤認しない。

### 2. 六 variant の決定的 routing

variant 名は ABI helper が次の文字列へ一意に決める。すべて depth test=true、
depth compare=less であり、routing を持つ surface は `pelican_lighting_v1` hook 必須である。
lowering は選択 surface の blend/cull/depth state（depth compare を含む）を期待値と照合する。

| variant | blend | cull | depth write | pass | MASK contract |
|---|---|---|---|---|---|
| `opaque_single_sided` | opaque | back | true | `forward_opaque` | — |
| `opaque_double_sided` | opaque | none | true | `forward_opaque` | — |
| `mask_single_sided` | opaque | back | true | `forward_opaque` | float `alpha_cutoff` 必須 |
| `mask_double_sided` | opaque | none | true | `forward_opaque` | float `alpha_cutoff` 必須 |
| `blend_single_sided` | blend | back | false | `forward_transparent` | — |
| `blend_double_sided` | blend | none | false | `forward_transparent` | — |

MASK の `alpha >= alpha_cutoff` 境界 helper、front/back visibility helper、六 state の
byte-stable text dump を追加した。single-sided は front=true/back=false、double-sided は
front=true/back=true を全 alpha mode で検証する。
実際の OpenPBR opacity sampling/discard code は M-PBR0b wrapper 本体で実装する。

### 3. GLB primitive binding ABI

新 schema は `pelican.material_bindings` v1 である。配列順と数値 index をそのまま保存する
byte-stable dump を持つ。

```json
{
  "schema": "pelican.material_bindings",
  "version": 1,
  "model": "project://imports/openpbr.glb",
  "bindings": [
    {
      "usd_path": "/World/Looks/LeafSubset",
      "mesh": 0,
      "primitive": 3,
      "material": "imported_mask",
      "routing": {
        "alpha_mode": "mask",
        "double_sided": true
      }
    }
  ]
}
```

意味は次の一方向 mapping である。

```text
USD prim/subset absolute path
    -> source GLB mesh index + primitive index
    -> Pelican material name + six-variant routing
    -> GlobalMaterialId
```

model asset declarationには任意の `material_bindings` reference を追加できる。

```json
{
  "name": "openpbr_scene",
  "path": "assets/imports/openpbr.glb",
  "material_bindings": "assets/imports/openpbr.material_bindings.json"
}
```

- GLTF prepare/commit は GPU offset と独立した source `mesh_index` / `primitive_index` を
  `ModelPrimitiveRefInfo` に保存する。
- mapping は whole-model 契約であり、ロード済みの全 source primitive がちょうど一度対応する。
  同じ GLB mesh が複数 node で instance 化されている場合、同じ source binding を全 occurrence へ適用する。
- model template は resolver callback で material 名/routing を `GlobalMaterialId` へ解決し、primitive を
  resolved material ごとに再編成する。現行 model asset consumer は GLTF commit が公開する named material を
  既定 namespace として即時消費できる。M-PBR0b/U-USD0c が外部 Pelican material を登録する時も、
  schema を変えず同じ resolver ABI へ登録済み ID を渡せる。
- model asset の initial load、inspect/validate、hot-reload commit の全経路に binding を適用する。
- document `model` と asset declaration の物理 model が同一でなければ hard error。
- fragment model/reference、duplicate USD path、同一 mesh/primitive collision、存在しない target、
  mapping 欠落、存在しない/重複 material 名を、model/USD/material/index 名入り hard error にする。

### 4. dev CLI

従来の一引数形式は byte 不変のまま、次の optional 引数を追加した。

```text
pelican_cli dump-lowered-material <surface> [material.json] [material-name]
```

material を指定した dump は texture override の最終 reference、六 variant 名、alpha/double-sided、
render state、forward target pass、MASK discard contract を表示する。

## `design_usd_openpbr.md` v2.1 §1-1 対応

| §1-1 | 実装結果 |
|---|---|
| 1. input 置き場表 | 本レポートの表で base/specular/IOR/coat/emission/normal/alpha と `doubleSided` を surface param/custom texture/render state/lighting に配置 |
| 2. shading 経路 | `pelican_lighting_v1` + forward を採用。opaque/mask=`forward_opaque`、blend=`forward_transparent`。PelicanSurfaceV2/G-buffer は追加せず |
| 3. custom texture override | `pelican.material.textures`、parser、lowering、binder、reload signature を additive に追加。宣言済み slot だけ許可 |
| 4. alpha/render state + doubleSided | `M-PBR0a-STATE` の三 alpha × 二 cull、固定 depth/blend、MASK cutoff ABI、六 state dumpを実装 |
| 5. material → primitive binding | `pelican.material_bindings` v1、source primitive coordinates、model template/asset consumer、whole-model error contract を実装 |
| 6. gate | CLI dump、schema invalid fixture、六 state dump、binding fixture、既存 material/golden byte gate、full build/test/player を完走 |

## fixture とテスト

追加した主な fixture/test は次のとおり。

- material parser: 宣言済み texture override、未宣言名、非 string、routing 型。
- binding schema: valid six variants、duplicate USD path、target collision、fragment model、routing 型。
- lowering/routing: 六 variant の state/forward/lighting hook、state mismatch、front/back visibility、
  MASK `alpha_cutoff` 必須、cutoff の直前/一致/直後。
- model template: primitive material swap、mapping 欠落、missing material、fragment reject、
  texture resolver binder。
- CLI: `wp116_mask_double.surface` + `wp116_mask_double.json` の lowered dump。
- byte golden: `six_variants_dump.txt`。新しい image golden は追加していないため件数は 40/39 のまま。

## M-PBR0b 以後へ明示的に残したもの

- OpenPBR 1.1.1 lighting/BRDF GLSL 本体と六つの production `.surface` wrapper。
- input の unit/range/default/colorspace/channel、texture slot 名、MaterialX/UsdPreviewSurface/glTF KHR 写像表。
- authored non-default/contributing connection に対する unsupported WARN code。
- OpenPBR の数値・画像 golden、production wrapper の実描画 golden、primitive binding の実画像 golden。
- USD import/toolchain、MaterialX allowlist、外部 Pelican material の runtime registration。
- PelicanSurfaceV2、G-buffer 拡張、deferred OpenPBR、任意 material-level pipeline override。

従って、この変更は OpenPBR を描いたと主張せず、M-PBR0b が安全に実装・接続できる ABI と
hard-error 境界だけを確定している。

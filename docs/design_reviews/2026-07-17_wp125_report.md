# WP125 完了レポート — XR0 OpenXR build unit / activation

## 1. 結論

WP125 の OpenXR build unit と runtime activation 三値を実装した。
`PELICAN_WITH_OPENXR` は開発 build で既定 ON、配布 preset では明示
`--with openxr` のときだけ ON になる。runtime 既定は `--xr off` のままである。

XR0 の境界どおり、XrInstance、XrSession、OpenXR runtime discovery は実装していない。
Vulkan resource 作成前の composition root に discovery hook を置き、XR1a が実体を差すまで
`hook_unavailable` を返す。レンダラーとループは変更していない。

## 2. 逐語受け入れ条件との対応

### XR0-BUILD-ACTIVATION（逐語）

> 「`PELICAN_WITH_OPENXR` は default ON の private unit とし、OFF では
> OpenXR source/object/library/symbol を binary から除去する。runtime activation は
> off/auto/on の三値で、explicit on の unavailable は hard error、auto の
> unavailable は名前入り INFO + flat とする。headless/RPC/golden/replay は
> XR off を強制する。OpenXR-SDK は exact commit 固定・不要 target OFF とし、
> single-OFF smoke と full-build flat golden byte 一致を gate にする。」

| 条件 | 実装・証跡 |
|---|---|
| default ON private unit | ルート option は ON。`pelican_openxr` static unit を `pelican_core` から PRIVATE link し、同 unit が `OpenXR::openxr_loader` を PRIVATE link |
| OFF で source/object/library/symbol 除去 | `src/core/openxr` の subdirectory 自体を条件化。single-OFF smoke が SDK fetch dir、build metadata、object/library、`queryDiscovery@OpenXr` と Xr API symbol の不在を検査 |
| off/auto/on | `EngineLaunchConfig::xr_mode` と player `--xr off|auto|on`。既定 `off` |
| on hard error / auto INFO + flat | `resolveXrActivation` が同じ discovery result から on は例外、auto は一個の INFO 文と flat decision を返す |
| 強制 off driver | headless、RPC、golden、replay を表駆動 fixture で検査。auto は discovery せず flat、on は名前入り error |
| SDK exact pin / 不要 target OFF | §3 の commit。API layer、test、conformance、sample、all-extension、force-generation を OFF。OpenGL helper target も ALL から除外 |
| gates | Debug full build、single-OFF smoke、全 CTest、45 case の actual RGBA8 diff 0 を完走 |

### XR0-ACTIVATION-EDGE（逐語）

> 「通常 window 起動では `--xr off` は probe なしの flat、
> `--xr auto` は runtime/system/graphics-binding 不在時に名前入り INFO を一回出して flat、
> `--xr on` は同じ不在・不適合を名前入り hard error とする。headless、RPC、golden、
> replay では `off` は flat、`auto` は OpenXR discovery を行わず off に正規化、
> explicit `on` は `--xr on is incompatible with <mode>` の名前入り hard error とする。
> `PELICAN_WITH_OPENXR=OFF` binary では `on` の error に同 build flag 名を含め、
> `auto` は INFO + flat とする。配布 v1 は
> `pelican_cli dist-config <project> --with openxr` だけが
> `PELICAN_WITH_OPENXR=ON` を preset へ入れる明示入力で、省略時は配布 preset で OFF とする。
> これは runtime 既定 `xr=off` を変更しない。compile ON/OFF × mode off/auto/on ×
> window/強制-off driver の表駆動 fixture を XR0 gate にする。」

| 条件 | 実装・fixture |
|---|---|
| window off | flat、hook call 0、INFO なし |
| window auto | compile ON は hook call 1。unavailable 名を含む INFO 一個と flat。compile OFF は hook call 0、`PELICAN_WITH_OPENXR=OFF` INFO と flat |
| window on | compile ON は unavailable 名入り例外。compile OFF は `PELICAN_WITH_OPENXR=OFF` と `--xr on` を含む例外 |
| forced driver off/auto | off はそのまま flat。auto は hook call 0、resolved mode off |
| forced driver on | `--xr on is incompatible with headless|RPC|golden|replay`。compile OFF 行は同時に build flag 名を含む |
| dist-config | `DistConfigOptions/Result`、preset comment/cache entry、CMake fixture に openxr を追加。省略 OFF、`--with rpc,seqplayer,openxr` のみ ON |
| 表駆動 gate | compile 2 × mode 3 × driver 5（window + 4 forced driver）= 30 dynamic sections。追加で available auto/on と runtime/system/graphics-binding unavailable を注入 |

## 3. OpenXR-SDK pin と unit 境界

- upstream: `KhronosGroup/OpenXR-SDK-Source`
- release: `release-1.1.61`
- annotated tag object: `d88065f9be355be507b326fe5d65f7b2f479dfab`
- **pin commit（peeled）**: `211e2f4f0b79932300a845f3a8ed75026dbfa4a3`
- loader: static、`OpenXR::openxr_loader` を private link
- OFF: FetchContent 宣言・unit subdirectory・unit source のいずれにも入らない

private unit の XR0 source は `openxrdiscovery.cpp` 一個だけである。OpenXR 1.1 header の
compile-time pin を確認するが API call は行わず、hook は
`OpenXR discovery hook unavailable (XR1a)` を返す。

## 4. activation fixture 一覧

`xractivation_test.cpp` の主表は次の 30 行を生成する。

| build | mode | driver（各 mode で全て） |
|---|---|---|
| OFF | off / auto / on | window、headless、RPC、golden、replay |
| ON | off / auto / on | window、headless、RPC、golden、replay |

各行で error の有無、error/INFO の名前、resolved mode、active、discovery call 数を検査する。
別表で available hook の auto/on が active になること、runtime/system/graphics-binding の
各 unavailable が OpenXR 名入り INFO で flat になることも検査する。

single-OFF smoke は実 binary に対して次を検査する。

1. `PELICAN_WITH_OPENXR=OFF` で configure と Debug full build。
2. OpenXR SDK の source/build/subbuild directory が作られない。
3. OpenXR unit source が build metadata に無く、unit object/library が無い。
4. `pelican_core.lib` と `pelican_player.exe` に discovery/Xr API symbol が無い。
5. `pelican_player --xr on` が失敗し、`PELICAN_WITH_OPENXR=OFF` を報告する。

## 5. 公開メッセージ

- compile OFF auto: `--xr auto: PELICAN_WITH_OPENXR=OFF; continuing in flat mode`
- discovery auto: `--xr auto: OpenXR <reason> unavailable; continuing in flat mode`
- discovery on: `--xr on: OpenXR <reason> unavailable`
- forced on: `--xr on is incompatible with <mode>`
- compile OFF forced on は上記 forced 文と `PELICAN_WITH_OPENXR=OFF` の両方を含む。

## 6. 検証結果

| gate | 結果 |
|---|---|

| Debug full build | 成功 |
| activation fixture | 2 root cases、196 assertions、失敗 0 |
| dist-config fixture | 成功。省略 OFF / `--with openxr` ON |
| single-OFF smoke | 成功。configure/build/source/object/library/symbol/CLI error を検査 |
| 全 CTest | 461/461、failure 0 |
| golden verbose | 7 test cases、417 assertions、SKIP marker 0 |
| image golden | VAT ON の 45 directories / 45 expected / 45 actual。全 metadata が `average_diff=0.0`, `max_diff=0` |
| player | `projects/example`、runtime 既定 `xr=off`、hidden window で 8.072 秒生存。fatal/validation 0、stderr 0 byte、停止後残存 process 0 |

全 CTest の末尾に表示される既存 conditional skip は、Windows の symlink 作成権限に依存する
`PathResolver rejects symlink escapes after canonicalization` 一件だけである。activation/golden の
skip ではない。

example の binary assets は worktree に追跡されていないため、player gate は過去 WP と同じく
sibling checkout `C:/src/pelican2/projects/example/assets` を一時
`.pelican/local.json` で参照した。gate 後に override と生成 cache を削除した。

## 7. スコープ確認

- XrInstance / XrSession / reference space / runtime discovery: 未実装（XR1a 以降）。
- renderer / frame loop / Vulkan bootstrap: 変更なし。
- golden の追加・更新: なし。
- runtime 既定: `xr=off`。既存 flat 起動を維持。

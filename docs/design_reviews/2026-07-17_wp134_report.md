# WP134 完了レポート — VRM-S1c bone lookAt + firstPerson

日付: 2026-07-17
ブランチ: `agent/wp134-s1c`

## 結論

WP134 を完了した。VRM 1.0 bone lookAt は phase 間で共有される mutable local pose
staging を通して eye rotation を適用し、後続 priority 300 callback が同じ pose を
観測した後に model pose / skin palette を再構築して一度だけ renderer へ commit する。

firstPerson は一般 primitive の glTF node identity を保持し、`auto` を engine load 時に
Head bone とその子孫への正の skin weight から triangle 単位で厳密分割する。OpenXR の
各 eye view は first-person visibility、通常の flat view は third-person visibility を選び、
material / shadow / velocity の全 draw 経路が同じ per-view range を使用する。

凍結済み `src/core/userpublic/animation/abi_v1.hpp` と `src/core/ecs/` は無変更である。
既存 WP123 expression の解決式、override、transaction は変更していない。

仕様参照:

- [VRM 1.0 lookAt](https://github.com/vrm-c/vrm-specification/blob/master/specification/VRMC_vrm-1.0/lookAt.md)
- [VRM 1.0 firstPerson](https://github.com/vrm-c/vrm-specification/blob/master/specification/VRMC_vrm-1.0/firstPerson.md)

## pose staging の公開面

新しい公開ヘッダーは
`src/core/userpublic/animation/pose_staging_v1.hpp` である。既存 ABI の末尾追記ではなく、
`getPoseStagingServiceV1` という別 entry point で service version 1 を negotiation する。

| 公開要素 | 契約 |
|---|---|
| `PoseStageHandle` | 1 phase run 内の staged pose identity / generation |
| `PoseStagingServiceV1` | capability と関数 table |
| `acquire_staged_pose` | active instance / frame revision の mutable local pose と共有 model pose を取得 |
| `resolve_source_node` | glTF source node index を active pose layout index へ変換 |
| capability | deferred commit、mutable local pose、source node mapping |

service version 不一致は `unsupported_version`、予約 field、instance、revision、stage
generation の不整合は既存 status 規則に従い fail-fast する。frame arena の pose lifetime は
変えず、staging view は当該 phase run の終了までだけ有効である。

## phase と commit

1. `parameter_snapshot` で WP123 入力 snapshot を固定する。
2. `base_pose_and_root_modifier` の active source publish は renderer へ即時送信せず、palette
   bytes と pose handles を staging へ保持する。
3. `world_post_process` priority 100 で、bone lookAt の leftEye / rightEye source node を
   layout node へ解決し、共有 local pose の rotation を絶対値で置換する。
4. priority 200 の既存 expression resolve は従来どおり動作する。
5. priority 300 の constraint callback は priority 100 と同じ `PoseStageHandle` / local pose
   bytes を観測できる。
6. 全 callback 成功後に local-to-model と skin palette を再計算し、最終 pose frame を一度
   commit する。callback または最終検証失敗時は pose commit しない。

bone rangeMap は入力角の絶対値を `inputMaxValue` で上限化し、比率へ
`outputScale` を掛ける。`inputMaxValue == 0` は入力 0 のときだけ 0、それ以外は
`outputScale` とする。yaw 正方向は left outer / right inner、yaw 負方向は
left inner / right outer、pitch 正方向は down、負方向は up を使い、VRM の Y-X-Z
順に相当する `Y yaw * X pitch` quaternion を eye local rotation とする。

## firstPerson auto split

`ModelPrimitiveRefInfo` と `RenderCommand` に source `node_index` と
`PrimitiveViewVisibility` を追加した。split は次の確定手順で engine load 中に行う。

1. humanoid `head` の glTF node から child edge を DFS し、Head と全子孫の bitset を作る。
2. skin の `JOINTS_0` component ごとに、対応 `WEIGHTS_0` が厳密に正の場合だけ skin joint
   node を調べる。zero weight の Head 参照は無視する。
3. 三角形の 3 vertex の一つでも Head 関連 weight を持てば、その三角形を
   `third_person_only` group、持たなければ `both` group とする。
4. 各 group 内の元 triangle 順を保存する。unindexed TRIANGLES は 0..N-1 index を生成する。
5. 両 group がある場合は vertex / morph delta を含む二つの immutable GPU primitive として
   登録する。近似、実行時 vertex 判定、import-tools への委譲は行わない。

annotation が無い VRM primitive も仕様どおり `auto` とする。明示 `both`、
`firstPersonOnly`、`thirdPersonOnly` は node identity を保ったまま split せず visibility へ
写す。未知 annotation と非 TRIANGLES auto は名前入り error とする。

## per-view visibility

indirect command buffer は material / source material / skin / visibility で一度だけ安定 sort し、
同じ immutable buffer 上に flat 用と first-person 用の draw range を構築する。view 間で
command bytes を書き換えない。

- flat view: `both` + `third_person_only`。通常 player、golden、mirror 等は既定でこちら。
- first-person view: `both` + `first_person_only`。WP131 OpenXR view builder は両 eye に
  `first_person_view = true` を明示する。

この選択は standard material draw だけでなく shadow depth と velocity draw にも渡る。
WP133 の graph variant / mirror / loop 実装には変更を加えていない。

# WP137 完了レポート — 負債 CI0: CPU gate の常設

## 1. 結果

Windows/MSVC の configure、Debug 全ターゲット build、GPU 不要 CTest を常設する
`.github/workflows/cpu-gate.yml` を追加した。CTest の `gpu` ラベルだけを選択境界とし、
`ctest -LE gpu` の JUnit に現れる未許可 SKIP を失敗させる。エンジンコード、テスト本体、
golden fileには変更を加えていない。自動 retry はない。

## 2. workflow

- trigger: 全 pull request と、統合ブランチ `codex/rendering-phase1-refactor` への push
- concurrency: pull request番号または ref 単位。古い同時 run は `cancel-in-progress: true`
- runner: `windows-latest`、MSVC、Debug
- toolchain: `actions/setup-python` の Python 3.12、Vulkan SDK 1.4.309.0
- 順序: SKIP policy checker単体テスト → configure (`SKIP_DEVSTUDIO=ON`) → 全ターゲット build →
  `test/ci/run_cpu_gate.py`
- CPU test選択: `ctest -LE gpu`。workflow内にテスト名リストや名前grepを持たない
- artifact: configure/build/CTestログ、JUnit、SKIP policy結果、`LastTest.log`、
  `CMakeConfigureLog.yaml`を成功・失敗に関係なく14日保存
- retry: なし。最初の失敗を赤とartifactに残す

外部 action はタグ名ではなく、確認時の commit SHA で固定した。

## 4. SKIP exact allowlist

`test/ci/run_cpu_gate.py`はCTestをJUnit付きで実行し、`Skipped` / `Not Run`を完全一致名で検査する。
allowlistは`test/ci/cpu_skip_allowlist.txt`で、現在の許可は次の一件だけである。

```text
PathResolver rejects symlink escapes after canonicalization
```

このテストはWindowsのdirectory symlink作成権限がなければSKIPし、権限があればPASSする。
allowlistにないSKIP、ワイルドカード、重複、CPU gateに存在しない古い許可名は失敗する。
checkerの単体テストには人工的な未許可SKIPを入れ、policy errorになることを固定した。

## 6. CI1 / CI2への引き継ぎ

CI1は本workflowを肥大化させず、`PELICAN_WITH_*` OFF matrix、
`run_build_units_smoke.cmake`、`run_project_code_smoke.cmake`、clean-clone self-contained projectを
別workflow/jobとして追加する。CI0の`gpu`選択とSKIP policyはそのまま維持し、自動 retryは導入しない。

CI2はVulkan deviceが保証されたrunnerを前提に、`-L gpu`側のgolden/player、validation layer、D-P5を
実行する。GPU不在はSKIP allowlistへ追加せずrunner misconfigurationとして失敗させる。golden、
validation、capture/trace artifactの詳細はCI2側で定義する。

GitHub上の実run確認は、指示どおり統合ブランチへpushされた後に行う。

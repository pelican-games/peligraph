# WP87 実装レポート — UI U1 GPU 描画

日付: 2026-07-12  
ブランチ: `agent/wp87-ui-gpu`

## 結果

WP87 の UI U1 を実装した。U0 のレイアウト／draw command 生成を GPU 描画へ接続し、20 byte の固定 quad ABI、`uint16` index、隣接 DrawRun マージ、`pelican.atlas` v1、nested clip、panel 9patch、image widget、purgeable UI feature を統合した。旧 `ui_overlay` の描画内容は strict `pelican.ui` v1 と atlas 参照へ atomic migration した。

## 実装内容

- `QuadVertex` を `pos float2@0 / uv float2@8 / linear RGBA8_UNORM@16 / stride 20` に固定し、サイズと全 offset を `static_assert` で保証した。1 quad は 4 vertex と 6 個の `uint16` index に展開する。
- 1 frame の上限を 16,384 quad／256 unique clip とし、超過は詳細付き `limit_exceeded` とした。
- stable sort 後、`pipeline_key / texture_page / sampler_key / clip_id` が一致する隣接 command だけを DrawRun に併合する。A-B-A の page 列は併合しない。
- strict `pelican.atlas` v1 parser を追加し、`#sprite/<name>` を page と right-exclusive rect に解決する。画像 page は `R8G8B8A8_SRGB` view、page 0 は white texel とした。bleed padding を前提に sprite rect から UV を生成する。
- nested clip は親子矩形を交差し、viewport px の整数 scissor と clip id に変換する。
- panel の 9patch と image widget を quad 群として描画する。linear color modulation と straight-alpha の linear blend を UI shader／pipeline に設定した。
- `engine://features/ui.json` を追加し、canonical anchor `pelican_ui` へ UI pass を挿入する構成へ移行した。feature が未参照なら `UiModule`、UI GPU resources、UI parser のいずれも生成しない。
- example の旧 inline `ui` pass と旧 `images` 形式を除去し、`pelican.ui` v1 と `pelican.atlas` v1 に移行した。`ui_test` と `explosion` の従来の配置・見た目を維持した。

## 受け入れ試験

構成:

```text
cmake -S . -B build_wp87 -DPython3_EXECUTABLE=%APPDATA%\uv\python\cpython-3.12.13-windows-x86_64-none\python.exe -DPELICAN_WITH_AUDIO=OFF -DPELICAN_WITH_EXR=OFF -DSKIP_DEVSTUDIO=ON
cmake --build build_wp87 --config Debug -j 6
```

結果:

- 全 CTest: `271/271`、失敗 `0`、`100% tests passed`。
- Windows で symlink を作成できない既存の PathResolver test 1 件だけが platform skip。WP87 の test／Golden に skip はない。
- Golden: `22/22` 成功、SKIP `0`。既存 21 case は final RGBA8 hash と renderer trace を含めて維持した。
- 新規 `ui_u1` Golden は 2 atlas page の A-B-A 交互描画、nested clip、9patch を検証する。
- U1 semantic gate、20 byte shader reflection／pipeline ABI、quad／index／上限、atlas bounds、nested clip、旧形式拒否、feature 不参照時の完全不生成を fixture で検証した。

## Player 実表示

Debug Player を example project で起動し、8 秒後にも正常描画が継続していることを確認した。1922×1112 のウィンドウキャプチャでは、3D scene の上に `ui_test` atlas と `explosion` atlas が従来の位置で同時表示されている。スクリーンショットは本 WP87 作業セッションの実機確認結果として添付した。

確認後は Player を終了し、検証用に一時 staging した ignored asset／project files を削除した。終了時に常駐 `pelican_player` process がないことを確認した。

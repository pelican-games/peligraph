# WP38 実装レポート: スケルタルアニメーション再生（クリップ v1）

日付: 2026-07-12
ブランチ: `agent/wp38-skeletal`

## 実装概要

- glTF の `skins`（joints / inverseBindMatrices）と `animations` を読み、
  `#animation/<名前>` の K1 解決結果を CPU クリップ表現へ接続した。複数 skin は
  primitive ごとの JOINTS_0 を 128 matrix の instance palette 内オフセットへ正規化する。
- 補間は LINEAR（translation / scale の lerp、rotation の shortest-path slerp）と
  STEP のみを実装した。CUBICSPLINE、未知 interpolation、morph target channel は
  animation 名を含むロードエラーとし、LINEAR への暗黙 fallback は行わない。
- `SkeletalModelData` が glTF node の親子と rest TRS を保持し、毎フレーム内部で
  world matrix と `jointWorld * inverseBindMatrix` を評価する。joint を ECS entity として
  生成せず、WP62 の scene graph と骨階層を分離した。
- scene component `animation` を追加した。`clip` / `speed` / `loop` / `start_time` を受け、
  省略値はそれぞれ 1.0 / true / 0.0。`graph` は v1 予約キーとして存在時に名前入りで拒否する。
  clip の GLB と描画 model の GLB が異なる場合も拒否する。
- sampling 時刻は `EngineTime::now()` のみを入力とする。同一時刻の palette を byte 比較する
  fixture を追加し、RPC `set_time` と固定 step が同じ決定的経路を使うようにした。

## GPU / shader variant

- 非スキン用 `CommonVertStruct`、既存 vertex buffer、既存 pipeline は変更せず、
  JOINTS_0 / WEIGHTS_0 を持つ専用 vertex buffer と
  `GraphicsPipelineDesc::use_skinned_vertex_layout` を追加した。
- palette は set 3 binding 2 の std430 matrix SSBO。`gl_BaseInstance * 128 + joint` で
  instance ごとの行列を参照する。material pipeline key に skinned layout を含め、
  `PELICAN_SKINNED` を既存 material/pass variant として扱う。
- 標準 PBR 用 `skinned.vert` と shadow depth 用 skinned pipeline を追加した。
  material main と shadow depth は draw batch ごとに regular/skinned vertex buffer と
  pipeline を選ぶ。非スキン batch の descriptor/layout は従来のままである。
- B 層 `surface_v1.vert` が `PELICAN_SKINNED` 時だけ palette を適用し、その後に既存の
  vertex hook / surface hook を呼ぶ。main / depth / velocity は同じ template を使う。
  `projects/example/shaders/toon.surface` は 1 byte も変更していない。

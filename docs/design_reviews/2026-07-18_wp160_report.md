# WP160 完了レポート — `pelican_rpc.py` 薄型 RPC クライアント

## 結果

WP160 の受け入れ条件を満たす Python 3.12 向けクライアントを追加した。
実装は標準ライブラリだけを使用し、エンジン C++ 側は変更していない。

- `PelicanRpc(project_dir, exe_path=None)` が player を
  `--rpc --headless --project <dir>` で起動し、stdin/stdout の NDJSON に接続する。
- `call(method, params=None)` が JSON-RPC 2.0 の id を採番し、result をそのまま返す。
- JSON-RPC error を `PelicanRpcError(code, message, data)` に変換する。
- get_status / step_frame / set_time / render_frame / capture / load_scene /
  scene_tree / get_components / list_assets / export_scene_snapshot の helper を追加した。
  すべて params 辞書を変換・検証せずエンジンへ渡すため、第二 serializer には
  なっていない。
- `with` 終了時は player を terminate し、終了しなければ kill して wait する。
- exe 省略時はリポジトリおよび cwd の祖先から
  `build/src/player/Debug/pelican_player.exe` を探索する。

## 使用例

リポジトリルートから次のように実行する。

```python
from tools.pelican_rpc import PelicanRpc, PelicanRpcError

try:
    with PelicanRpc("projects/mygame") as rpc:
        status = rpc.get_status()
        rpc.set_time({"t": 1.25})
        frame = rpc.step_frame()
        tree = rpc.scene_tree()
        print(status["scene"], frame["frame"], tree["objects"])
except PelicanRpcError as error:
    print(error.code, error.message, error.data)
```

別の build ツリーを使用するときは
`PelicanRpc(project_dir, exe_path=player_path)` と明示する。

## smoke test

`test/pelican_rpc_smoke.py` は一時ディレクトリに最小 project を作り、実際の
player に対して次を順に確認する。

1. `get_status` が `default_scene` を返す。
2. `step_frame` が frame を 1 増やす。
3. `scene_tree` が `default_scene` を返す。
4. context manager 終了後に player プロセスが残っていない。

CTest 名は `pelican_rpc_smoke`、ラベルは `gpu`、timeout は 120 秒、既存の
GPU テストと同じ `pelican_gpu` resource lock を使用する。

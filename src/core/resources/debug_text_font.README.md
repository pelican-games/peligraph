# debug_text bitmap font

`debug_text_font.png` and `debug_text_font.json` are generated by
`generate_debug_text_font.mjs`.

The glyph patterns in that generator were authored for this repository as a
small ASCII-only diagnostic bitmap font. They are dedicated to the public
domain under CC0-1.0. No external font file or system font is used.

Regenerate from the repository root with:

```sh
node src/core/resources/generate_debug_text_font.mjs
```
